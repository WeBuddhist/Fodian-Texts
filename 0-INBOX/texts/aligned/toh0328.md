# The Sūtra of Nanda’s Going Forth — aligned

|---|---|---|
| 1 | དགའ་བོ་རབ་ཏུ་བྱུང་བའི་མདོ། | 難陀出家經。 |
| 2 | ཐམས་ཅད་མཁྱེན་པ་ལ་ཕྱག་འཚལ་ལོ། ། | 頂禮一切智。 |
| 3 | འདི་སྐད་བདག་གིས་ཐོས་པའི་ | 如是我聞： |

| 5 | བཅོམ་ལྡན་འདས་སེར་སྐྱའི་གནས་ཀྱི་ནྱ་གྲོ་དྷའི་ཀུན་དགའི་ར་བ་ན་བཞུགས་སོ། ། | 世尊在迦毘羅衛國尼拘律樹園。 |
| 6 | དེ་ནས་བཅོམ་ལྡན་འདས་སྔ་དྲོ་ཆོས་གོས་དང་ཤམ་ཐབས་མནབས་ཏེ། | 爾時午前，世尊身著法衣、下裙， |
| 7 | ལྷུང་བཟེད་བསྣམས་ནས་ | 執鉢， |
| 8 | ཕྱི་བཞིན་འབྲང་བའི་དགེ་སྦྱོང་ཚེ་དང་ལྡན་པ་ཀུན་དགའ་བོ་དང་། | 與侍者沙門具壽阿難， |
| 9 | སེར་སྐྱའི་གནས་སུ་བསོད་སྙོམས་ལ་གཤེགས་སོ། ། | 共入迦毘羅衛國乞食。 |
| 10 | དེ་ནས་བཅོམ་ལྡན་འདས་རིགས་ཀྱི་བུ་དགའ་བོའི་ཁྱིམ་ག་ལ་བ་དེར་གཤེགས་པ་དང་། | 爾時，世尊至善男子難陀宅。 |
| 11 | རིགས་ཀྱི་བུ་དགའ་བོས་བཅོམ་ལྡན་འདས་རྒྱང་རིང་པོ་ནས་གཤེགས་པ་མཐོང་ངོ་། ། | 難陀見世尊自遠而來， |
| 12 | མཐོང་ནས་ཀྱང་རིངས་པ་རིངས་པར་བཅོམ་ལྡན་འདས་ཀྱི་ཆེད་དུ་གདན་བཤམས་ནས་ | 旋為世尊設座， |
| 13 | འདི་སྐད་ཅེས་གསོལ་ཏོ། ། | 而白佛言： |
| 14 | བཅོམ་ལྡན་འདས་ཚུར་གཤེགས། | 「世尊，請入。 |
| 15 | བཅོམ་ལྡན་འདས་གཤེགས་པ་ལེགས་སོ། ། | 世尊，善來。 |
| 16 | བཅོམ་ལྡན་འདས་གདན་བཤམས་པ་ལ་བཞུགས་སུ་གསོལ། | 世尊，願於此坐。」 |
| 17 | བཅོམ་ལྡན་འདས་བཞུགས་སོ། ། | 佛即就坐。 |
| 18 | དེ་ནས་རིགས་ཀྱི་བུ་དགའ་བོས་བཅོམ་ལྡན་འདས་ཀྱི་ཞབས་གཉིས་ལ་ཕྱག་འཚལ་ཏེ། | 爾時，難陀禮世尊雙足， |
| 19 | བཅོམ་ལྡན་འདས་ཀྱི་སྤྱན་སྔར་འདུག་གོ། ། | 坐世尊前。 |
| 20 | དེ་ནས་བཅོམ་ལྡན་འདས་ཀྱིས་རིགས་ཀྱི་བུ་དགའ་བོ་ལ་འདི་སྐད་ཅེས་བཀའ་སྩལ་ཏོ། ། | 世尊告善男子難陀曰： |
| 21 | དགའ་བོ་ཅིའི་ཕྱིར་རབ་ཏུ་མི་འབྱུང་། | 「難陀！云何不出家？」 |
| 22 | དགའ་བོས་གསོལ་པ། | 難陀白言： |
| 23 | བཅོམ་ལྡན་འདས་རབ་ཏུ་འབྱུང་བ་ཞེས་བྱ་བའི་ | 「世尊！言出家者， |
| 24 | ཚིག་གི་དོན་ཅི་ལགས། | 其義云何？」 |
| 25 | བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། | 世尊告曰： |
| 26 | སྡིག་པ་ཐམས་ཅད་ཡོངས་སུ་སྤོང་བ་ཡིན་ནོ། ། | 「出家者，能斷諸罪， |
| 27 | འདོད་ཆགས་དང་། ཞེ་སྡང་དང་། གཏི་མུག་རབ་ཏུ་སེལ་བ་ཡིན་ནོ། ། | 盡除三毒； |
| 28 | འཐབ་པ་དང་། ཐབ་མོ་དང་། མཚང་འདྲུ་བ་དང་། རྩོད་པ་དང་། འགྱེད་པ་དང་། སྒྱུ་དང་། གཡོའི་མུན་པས་བསྡུས་པའི་དྲི་མ་ཐམས་ཅད་འཁྲུ་བ་ཡིན་ནོ། ། | 擊打鬥諍，爭競訐露，欺誑諂曲，所集冥闇，皆悉能除。 |
| 29 | ལོ་ཏོག་ཐམས་ཅད་ཀྱི་ས་གཞི་ལྟ་བུར་ཡོན་ཏན་ཐམས་ཅད་ཀྱི་གཞི་ཡིན་ནོ། ། | 其如大地，是眾德本； |
| 30 | རིན་པོ་ཆེ་ཐམས་ཅད་ཀྱི་འབྱུང་གནས་ཡིན་ནོ། ། | 為眾珍寶生源之地， |
| 31 | བདེ་བ་ཐམས་ཅད་ཀྱི་ཡིད་བཞིན་གྱི་ནོར་བུ་ཡིན་ནོ། ། | 是諸安樂如意寶珠， |
| 32 | ཡོན་ཏན་ཐམས་ཅད་ཀྱི་གོ་འཕང་གི་གནས་ཡིན་ནོ། ། | 眾功德果所依止處。 |
| 33 | སེམས་ཅན་ཐམས་ཅད་དབུགས་འབྱིན་པ་ཡིན་ནོ། ། | 其能施與有情安慰， |
| 34 | འབྱུང་པོ་ཐམས་ཅད་ཀྱི་ཡིད་བརྟན་པ་ཡིན་ནོ། ། | 諸有情眾之所委信， |
| 35 | སྲོག་ཆགས་ཐམས་ཅད་ལ་མི་འཇིགས་པ་སྦྱིན་པ་ཡིན་ནོ། ། | 能予一切生靈無畏， |
| 36 | སེམས་ཅན་དབུལ་པོ་ཐམས་ཅད་ཀྱི་བུམ་པ་བཟང་པོ་ཡིན་ནོ། ། | 是貧困者如意寶瓶。 |
| 37 | སྐྱབས་མེད་པ་རྣམས་ཀྱི་དཔུང་གཉེན་ཡིན་ནོ། ། | 無歸依者，為作所趣。 |
| 38 | ཀུན་དུ་ཚོལ་བས་ཕོངས་པ་དང་སྡུག་བསྔལ་གྱིས་ཉམ་ཐག་པ་རྣམས་ཀྱི་བསྟི་ས་ཡིན་ནོ། ། | 遍求無著，為斯苦惱，所逼迫者，令得蘇息。 |
| 39 | སངས་རྒྱས་ཐམས་ཅད་ཀྱི་མ་འདྲེས་པ་ཡིན་ནོ། ། | 其為諸佛不共聖法， |
| 40 | སེམས་ཅན་ཐམས་ཅད་ཀྱིས་མཆོད་པར་བྱ་བ་ཡིན་ནོ། ། | 一切有情所應供養， |
| 41 | མཁས་པ་རྣམས་ཀྱིས་བསྔགས་པ་ཡིན་ནོ། ། | 諸有智者之所稱歎， |
| 42 | ཐར་པར་འགྲོ་བ་རྣམས་ཀྱི་ལམ་ཡིན་ནོ། | 趣解脫眾之所經行， |
| 43 | སེམས་ཅན་དག་པ་རྣམས་ཀྱི་བསྙེན་པར་བྱ་བ་ཡིན་ནོ། ། | 清淨眾生之所親近， |
| 44 | སྣོད་དུ་གྱུར་པ་རྣམས་ཀྱིས་བསྟེན་པར་བྱ་བ་ཡིན་ནོ། ། | 堪成法器所應依止。 |
| 45 | ངན་སོང་གི་སྒོ་གཅོད་པ་ཡིན་ནོ། ། | 能閉惡趣之戶， |
| 46 | མཐོ་རིས་དང་ཐར་པའི་སྒོ་འབྱེད་པ་ཡིན་ནོ། ། | 能開善趣、解脫之門， |
| 47 | ལྷའི་འགྲོ་བ་རྣམས་ཀུན་དུ་འགེངས་པ་ཡིན་ནོ། ། | 諸天遍滿； |
| 48 | སྡུག་བསྔལ་ཐམས་ཅད་ཀུན་དུ་གཅོད་པ་ཡིན་ནོ། ། | 一切諸苦，皆得斷盡； |
| 49 | སྲེད་པའི་འཆིང་བས་བཅིངས་པ་རྣམས་རྣམ་པར་གྲོལ་བར་བྱེད་པ་ཡིན་ཏེ། | 愛索纏縛，能令開解。 |
| 50 | དགའ་བོ་དེ་ནི་རབ་ཏུ་བྱུང་བ་ཞེས་བྱའོ། ། | 難陀！此謂出家。」 |
| 51 | ཡང་དག་པའི་ལྟ་བའི་ཁྱིམ་ཡིན་ནོ། ། | 其為正見依處， |
| 52 | ཐར་པའི་ཡང་དག་པར་སྡོམ་པ་ཡིན་ནོ། | 解脫正戒， |
| 53 | མྱ་ངན་ལས་འདས་པ་ལ་བསྙེན་པ་ཡིན་ནོ། ། | 親近涅槃， |
| 54 | རྒྱུན་ཉེ་བར་གཅོད་པ་ཡིན་ནོ། ། | 截斷續流， |
| 55 | ཉོན་མོངས་པ་རྣམས་སྲེག་པ་ཡིན་ནོ། ། | 焚諸煩惱， |
| 56 | ཕྲ་རྒྱས་རྣམས་འབྱིན་པ་ཡིན་ནོ། ། | 盡諸隨眠； |
| 57 | ལྟ་བ་ངན་པའི་དྲ་བ་རྣམས་འཇིག་པར་བྱེད་པ་ཡིན་ནོ། ། | 能壞惡見網罟， |
| 58 | བདུད་ཀྱི་རྒྱལ་མཚན་སྙོལ་བ་ཡིན་ནོ། ། | 傾倒魔羅邪幢， |
| 59 | བཟོད་པ་སྨྲ་བ་སྒྲེང་བ་ཡིན་ནོ། ། | 樹說忍教， |
| 60 | འཁོར་བའི་འཁོར་ལོ་ལྡོག་པར་བྱེད་པ་ཡིན་ནོ། | 止流轉輪， |
| 61 | ཆོས་ཀྱི་འཁོར་ལོ་སྐོར་བར་བྱེད་པ་ཡིན་ནོ། ། | 轉動法輪， |
| 62 | ནུ་ཞོའི་རྒྱ་མཚོ་སྐེམས་པ་ཡིན་ནོ། ། | 竭母乳海， |
| 63 | རུས་པའི་རི་འཇིག་པར་བྱེད་པ་ཡིན་ནོ། ། | 壞骨鎖山， |
| 64 | སྐྱེ་བ་དང་། རྒ་བ་དང་། ན་བ་དང་། འཆི་བའི་མཐའ་ཡིན་ནོ། ། | 臻至生老病死之邊際也。 |
| 65 | ཕུང་པོའི་ཁུར་འཇོག་པ་ཡིན་ནོ། ། | 五蘊重袱，於是卸除； |
