| 6 | བཅོམ་ལྡན་འདས་རྒྱལ་པོའི་ཁབ་བྱ་རྒོད་ཕུང་པོའི་རི་ལ་བཞུགས་སོ། ། | 世尊住王舍城耆闍崛山， | 世尊住王舍城耆闍崛山， |
| 7 | བྱང་ཆུབ་སེམས་དཔའ་ཚད་མེད་གྲངས་མེད་པ་དང་། ལྷ་དང་། ཀླུ་དང་། འཁོར་ཐམས་ཅད་དང་ཐབས་ཅིག་ཏུ་བཞུགས་ཏེ། | 與無量無數菩薩及天、龍等一切眷屬俱。 | 與無量無數菩薩及天、龍等一切眷屬俱。 |
| 8 | བཅོམ་ལྡན་འདས་ལ་བཀུར་སྟིར་བགྱིད་ཅིང་མཆོད་དོ། ། | 〔彼等皆〕於世尊恭敬供養。 | 〔彼等皆〕於世尊恭敬供養。 |
| 9 | དེའི་ཚེ་འཁོར་དེར་བྱང་ཆུབ་སེམས་དཔའ་སའི་སྙིང་པོ་འདུག་པ་སྟན་ལས་ལངས་ནས། | 爾時，地藏菩薩於彼會中從座而起， | 爾時，地藏菩薩於彼會中從座而起， |
| 10 | བཅོམ་ལྡན་འདས་ལ་འདི་སྐད་ཅེས་གསོལ་ཏོ། ། | 白世尊言： | 白世尊言： |
| 11 | བཅོམ་ལྡན་འདས་ལ་སྐུ་དུ་མངའ། | 「世尊之身，為有幾何？」 | 「世尊之身，為有幾何？」 |
| 12 | བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། | 世尊告曰： | 世尊告曰： |
| 13 | སའི་སྙིང་པོ་བཅོམ་ལྡན་འདས་དེ་བཞིན་གཤེགས་པ་ལ་སྐུ་གསུམ་མངའ་སྟེ། ཆོས་ཀྱི་སྐུ་དང་། ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་དང་། སྤྲུལ་པའི་སྐུའོ། ། | 「地藏！世尊如來有三身，謂：法身、受用身、變化身。 | 「地藏！世尊如來有三身，謂：法身、受用身、變化身。 |
| 14 | རིགས་ཀྱི་བུ་དེ་བཞིན་གཤེགས་པའི་སྐུ་གསུམ་ནི་ | 善男子！如來三身者： | 善男子！如來三身者： |
| 15 | རང་བཞིན་རྣམ་པར་དག་པ་ནི་ཆོས་ཀྱི་སྐུའོ། ། | 自性清淨乃法身； | 自性清淨乃法身； |
| 16 | ཏིང་ངེ་འཛིན་རྣམ་པར་དག་པ་ནི་ལོངས་སྤྱོད་རྫོགས་པའི་སྐུའོ། ། | 三昧清淨乃受用身； | 三昧清淨乃受用身； |
| 17 | སྤྱོད་པ་རྣམ་པར་དག་པ་ནི་སངས་རྒྱས་ཐམས་ཅད་ཀྱི་སྤྲུལ་པའི་སྐུའོ། ། | 所行清淨乃諸佛變化身。 | 所行清淨乃諸佛變化身。 |
| 18 | རིགས་ཀྱི་བུ་དེ་བཞིན་གཤེགས་པའི་ཆོས་ཀྱི་སྐུ་ནི་ནམ་མཁའ་ལྟར་རང་བཞིན་མེད་པའི་དོན་ནོ། ། | 善男子！如來法身者，猶如虛空，是無自性義； | 善男子！如來法身者，猶如虛空，是無自性義； |
| 19 | ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་ནི་སྤྲིན་ལྟར་འབྱུང་བའི་དོན་ནོ། ། | 受用身者，如雲，是現起義； | 受用身者，如雲，是現起義； |
| 20 | སྤྲུལ་པའི་སྐུ་ནི་སངས་རྒྱས་ཐམས་ཅད་ཀྱི་ཕྲིན་ལས་ཏེ། ཆར་བ་ལྟ་བུ་སྟེ་ཐམས་ཅད་བངས་པའི་དོན་ནོ། ། | 變化身者，為諸佛事業，如雨，是普潤義。」 | 變化身者，為諸佛事業，如雨，是普潤義。」 |
| 21 | བཅོམ་ལྡན་འདས་ལ་བྱང་ཆུབ་སེམས་དཔའ་སའི་སྙིང་པོས་འདི་སྐད་ཅེས་གསོལ་ཏོ། ། | 地藏菩薩白世尊言： | 地藏菩薩白世尊言： |
| 22 | བཅོམ་ལྡན་འདས་ཀྱི་སྐུ་གསུམ་གྱི་བཤད་པ་ཇི་ལྟར་བལྟ་བར་བགྱི། | 「於世尊三身之說，應云何觀？」 | 「於世尊三身之說，應云何觀？」 |
| 23 | བཅོམ་ལྡན་འདས་ཀྱིས་བྱང་ཆུབ་སེམས་དཔའ་སའི་སྙིང་པོ་ལ་བཀའ་སྩལ་པ། | 世尊告地藏菩薩曰： | 世尊告地藏菩薩曰： |
| 24 | རིགས་ཀྱི་བུ་དེ་བཞིན་གཤེགས་པའི་སྐུ་གསུམ་ནི་འདི་ལྟར་བལྟ་བར་བྱའོ། ། | 「善男子！於如來三身，應作如是觀： | 「善男子！於如來三身，應作如是觀： |
| 25 | ཆོས་ཀྱི་སྐུ་ནི་དེ་བཞིན་གཤེགས་པའི་ངོ་གང་ལ་བལྟ་བར་བྱའོ། ། | 於如來前為法身， | 於如來前為法身， |
| 26 | ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་ནི་བྱང་ཆུབ་སེམས་དཔའི་ངོ་གང་ལ་བལྟ་བར་བྱའོ། ། | 於菩薩前為受用身， | 於菩薩前為受用身， |
| 27 | སྤྲུལ་པའི་སྐུ་ནི་མོས་པས་སྤྱོད་པའི་སོ་སོ་སྐྱེ་བོའི་ངོ་གང་ལ་བལྟ་བར་བྱའོ། ། | 於信解行〔地〕凡夫前為變化身。 | 於信解行〔地〕凡夫前為變化身。 |
| 28 | རིགས་ཀྱི་བུ་ཆོས་ཀྱི་སྐུ་ནི་སངས་རྒྱས་ཐམས་ཅད་དང་རང་བཞིན་འཐུན་པར་གནས་སོ། ། | 「善男子！法身者，即諸佛自性等同； | 「善男子！法身者，即諸佛自性等同； |
| 29 | ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་ནི་སངས་རྒྱས་ཐམས་ཅད་དང་ཏིང་ངེ་འཛིན་འཐུན་པར་གནས་སོ། ། | 受用身者，即諸佛三昧等同； | 受用身者，即諸佛三昧等同； |
| 30 | སྤྲུལ་པའི་སྐུ་ནི་སངས་རྒྱས་ཐམས་ཅད་དང་ཕྲིན་ལས་འཐུན་པར་གནས་སོ། ། | 變化身者，即諸佛事業等同。 | 變化身者，即諸佛事業等同。 |
| 31 | རིགས་ཀྱི་བུ་ཀུན་གཞི་གནས་སུ་དག་པ་ནི་མེ་ལོང་ལྟ་བུའི་ཡེ་ཤེས་ཏེ་ཆོས་ཀྱི་སྐུའོ། ། | 「善男子！阿賴耶〔識〕轉依，得大圓鏡智，即是法身。 | 「善男子！阿賴耶〔識〕轉依[^0]，得大圓鏡智，即是法身[^1]。 |
| 32 | ཉོན་མོངས་པའི་ཡིད་གནས་སུ་དག་པ་ནི་མཉམ་པ་ཉིད་ཀྱི་ཡེ་ཤེས་སོ། ། | 末那識轉依，得平等性智； | 末那識轉依，得平等性智[^2]； |
| 33 | ཡིད་ཀྱི་རྣམ་པར་ཤེས་པ་གནས་སུ་དག་པ་ནི་སོ་སོར་ཀུན་དུ་རྟོག་པའི་ཡེ་ཤེས་ཏེ། ལོངས་སྤྱོད་རྫོགས་པའི་སྐུའོ། ། | 意識轉依，得妙觀察智，〔此二智〕即受用身。 | 意識轉依，得妙觀察智，〔此二智〕即受用身[^3]。 |
| 34 | སྒོ་ལྔའི་རྣམ་པར་ཤེས་པ་གནས་སུ་དག་པ་ནི་བྱ་བ་གྲུབ་པའི་ཡེ་ཤེས་ཏེ་སྤྲུལ་པའི་སྐུའོ། ། | 五根識轉依，得成所作智，即變化身。」 | 五根識轉依，得成所作智，即變化身[^4]。」 |
| 35 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་སའི་སྙིང་པོས་བཅོམ་ལྡན་འདས་ལ་འདི་སྐད་ཅེས་གསོལ་ཏོ། ། | 爾時，地藏菩薩白世尊言： | 爾時，地藏菩薩白世尊言： |
| 36 | བཅོམ་ལྡན་འདས་བདག་གིས་བཅོམ་ལྡན་འདས་ལ་དམ་པའི་ཆོས་ཐོས་པ་ནི་རབ་ཏུ་ལེགས་སོ། ། | 「世尊！我於世尊處，聞微妙法，甚善！ | 「世尊！我於世尊處，聞微妙法，甚善！ |
| 37 | བདེ་བར་གཤེགས་པ་རབ་ཏུ་ལེགས་སོ། ། | 善逝！甚善！」 | 善逝！甚善！」 |
