| 21 | འཁོར་གྱི་དཀྱིལ་འཁོར་མང་པོ་རྣམས། ། | 周圍眷屬眾， |

| 23 | ཤིན་ཏུ་ལེགས་སོ་ཉི་ཟླའི་འོད། ། | 甚善日月光， |
| 24 | ཅང་མི་གསུང་བར་སྣང་མི་མཛད། ། | 歛照默然住； |
| 25 | ཤིན་ཏུ་ལེགས་སོ་རིན་ཆེན་གཏེར། ། | 甚善珍寶藏， |
| 26 | དབུལ་ཕོངས་རྣམས་ལ་སྦྱིན་མི་མཛད། ། | 不施貧乏眾； |
| 27 | ཤིན་ཏུ་ལེགས་སོ་མི་ཡི་རྒྱལ། ། | 甚善人中王， |
| 28 | ཏིང་ངེ་འཛིན་ལས་བཞེངས་སུ་གསོལ། ། | 請從三昧出。 |
| 29 | ཤིན་ཏུ་ལེགས་སོ་ཀླུ་ཡི་རྒྱལ། ། | 甚善龍王者， |
| 30 | བདུད་རྩིའི་ཆར་པ་དབབ་ཏུ་གསོལ། ། | 請降甘露雨。 |
| 31 | ཤིན་ཏུ་ལེགས་སོ་ལྷ་ཡི་མཆོག ། | 甚善天中尊， |
| 32 | མྱུར་དུ་ཆོས་རྣམས་བསྟན་དུ་གསོལ། ། | 請速演諸法。 |
| 33 | ཤིན་ཏུ་ལེགས་སོ་སེམས་ཅན་ལ། ། | 甚善為有情， |
| 34 | ཐེག་པ་གཅིག་དོན་བསྟན་དུ་གསོལ། ། | 請演一乘義 。」 |
| 35 | དེ་ནས་བཅོམ་ལྡན་འདས་ཏིང་ངེ་འཛིན་དེ་ལས་བཞེངས་ནས་ | 爾時，世尊即從三昧起， |
| 36 | འཁོར་མང་པོ་རྣམས་ལ་འདི་སྐད་ཅེས་བཀའ་སྩལ་ཏོ། ། | 告眾眷屬言： |
| 37 | ང་ལ་རིན་པོ་ཆེ་བླ་ན་མེད་པའི་ཡེ་ཤེས་མང་དུ་ཡོད་པ་ | 「我有諸多無上寶智， |
| 38 | ཁྱོད་ལ་ཕན་པ་དང་བདེ་བར་མཛད་ཅིང་ | 能令汝等利益安樂 ， |
| 39 | དབུལ་ཕོངས་པ་དང་བྲལ་བར་བྱ་བ་ཡོད་ཀྱིས་ | 遠離貧乏， |
| 40 | ཐེ་ཙོམ་མ་བྱེད་པར་ཅི་དང་ཅི་འདོད་པ་དྲིས་ཤིག ། | 是故勿疑，欲問便問。」 |

| 43 | སངས་རྒྱས་ལ་འདི་སྐད་ཅེས་གསོལ་ཏོ། ། | 即白佛言： |

| 46 | མདོ་སྡེ་དག་ལས་བཤད་པ་ཐོས་པ་ལྟར་ན་ | 然依昔聞諸經所說， |
| 47 | མང་དུ་ཐོས་ཤིང་ཤེས་རབ་རྣོ་བའི་དབང་པོ་དང་ལྡན་པ་ནི་ | 多聞復具利慧根者， |
| 48 | བྱང་ཆུབ་ཐོབ་པ་ཤིན་ཏུ་དཀའ་སྟེ་བགེགས་བརྒྱད་དུ་ཞེས་འབྱུང་ན། | 彼於菩提，甚難證得，謂當有八魔。 |
| 49 | བདག་གིས་ཇི་ལྟར་བླ་ན་མེད་པའི་བྱང་ཆུབ་ཐོབ་པར་འགྱུར། | 〔若爾，〕我當云何得證無上菩提？」 |
| 50 | བཅོམ་ལྡན་འདས་ཀྱིས་དགའ་བོ་ལ་བཀའ་སྩལ་པ། | 世尊告阿難曰： |

| 56 | སེམས་ཏིང་ངེ་འཛིན་ལ་གནས་ན་ནི་ | 心住三昧， |

| 62 | གང་གིས་ཏིང་ངེ་འཛིན་དང་ཤེས་རབ་དང་ཤིན་ཏུ་ལྡན་ན་ | 凡彼備具三昧、智慧者， |

| 68 | བཅོམ་ལྡན་འདས་ཀྱིས་དགའ་བོ་ལ་བཀའ་སྩལ་པ། | 世尊告阿難曰： |
| 69 | དགའ་བོ་ | 「阿難！ |

| 73 | རིའི་ནང་ན་རི་རབ་ལྷུན་པོ་མཆོག་ཏུ་གྱུར་པ་ལྟ་བུའོ། ། | 亦如須彌，群山之最。 |

| 76 | མཆོག་དམ་པ་ཡིན་པའི་ཕྱིར་རོ། ། | 為最上妙故。」 |
| 77 | བཅོམ་ལྡན་འདས་ཀྱིས་དགའ་བོ་ལ་བཀའ་སྩལ་པ། | 世尊告阿難曰： |
| 78 | དགའ་བོ་ | 「阿難！ |
| 79 | གལ་ཏེ་མི་ཞིག་གིས་ཤིང་ཙན་དན་ལས་སྟོང་གསུམ་གྱི་སྟོང་ཆེན་པོའི་འཇིག་རྟེན་གྱི་ཁམས་གང་བའི་གཙུག་ལག་ཁང་བརྩིགས་པ་དང་། | 假使有人，以栴檀木，修造精舍，遍滿三千大千世界； |
