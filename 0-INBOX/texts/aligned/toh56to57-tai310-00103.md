| 7 | ཁྱིམ་བདག་ རྣམས་རྣ་བ་དང་། སྣ་དང་། ལྕེ་དང་། ལུས་དང་། ཡིད་ནི་འབྱུང་བ་ཆེན་པོ་བཞི་ལས་གྱུར་པ། མི་རྟག་པ། མི་བརྟན་པ། ཐེར་ཟུག་མ་ཡིན་པ། ཡིད་བརྟན་དུ་མི་རུང་བ། སྙིང་པོ་མེད་པ། ཞིགས་པ། ནད་ཅན། སྡུག་བསྔལ་བ། ནད་མང་བ། གཙེ་བ་མང་བ་ཡིན་ཏེ ཁྱིམ་བདག་ཁྱེད་རྣམས་ཀྱིས་ཡིད་དེ་ལ་གནས་པར་མི་བྱའོ། ། | 耳、鼻、舌、身、意亦復如是，不應依止，當如是觀。 |

| 11 | མིག་འདི་ནི་རིང་དུ་མི་གནས་ཏེ་ཆུའི་ཆུ་བུར་ལྟ་བུའོ། ། | 眼如浮泡不得久住， |
| 12 | མིག་འདི་ནི་ལས་དང་ཉོན་མོངས་པ་དང་། སྲེད་ པ་ལས་བྱུང་བ་སྟེ། སྨིག་རྒྱུ་ལྟ་བུའོ། ། | 眼如陽焰業惑愛生， |
| 13 | མིག་འདི་ནི་རང་བཞིན་གྱིས་སྙིང་པོ་མེད་དེ་ཆུ་ཤིང་ལྟ་བུའོ། ། | 眼如芭蕉性不堅固， |
| 14 | མིག་འདི་ནི་ཕྱིན་ཅི་ལོག་ལས་བྱུང་བ་སྟེ། སྒྱུ་མ་ལྟ་བུའོ། ། | 眼如幻術從顛倒起， |
| 15 | མིག་འདི་ནི་ལོག་པ་དང་། ཡང་དག་པ་མ་ཡིན་པ་མཐོང་བ་སྟེ། རྨི་ལམ་ལྟ་བུའོ། ། | 是眼如夢唯虛妄見， |
| 16 | མིག་འདི་ནི་རྐྱེན་ལ་རག་ ལས་པ་སྟེ་བྲག་ཅ་ལྟ་བུའོ། ། | 是眼如響繫屬眾緣， |
| 17 | མིག་འདི་ནི་ལས་ཀྱི་མིག་ཡོར་གྱིས་ཀུན་དུ་སྣང་བ་སྟེ་མིག་ཡོར་ལྟ་བུའོ། ། | 眼如光影業光影現， |
| 18 | མིག་འདི་ནི་སེམས་འཁྲུག་པ་མེད་པར་འགྱུར་བའི་མཚན་ཉིད་དེ་སྤྲིན་ལྟ་བུའོ། ། | 眼如浮雲聚亂散相， |
| 19 | མིག་འདི་ནི་སྐད་ཅིག་ཏུ་འཇིག་པ་དང་ལྡན་པ་སྟེ། གློག་ལྟ་བུའོ། ། | 眼如流電剎那便滅， |
| 20 | མིག་འདི་ནི་བདག་པོ་མེད་ དེ།  ས་དང་མཚུངས་སོ། ། | 是眼無主猶如地， |
| 21 | མིག་འདི་ནི་བདག་མེད་དེ་ཆུ་དང་མཚུངས་སོ། ། | 是眼無我猶如水， |
| 22 | མིག་འདི་ནི་སེམས་ཅན་མེད་དེ་མེ་དང་མཚུངས་སོ། ། | 眼非有情猶如火， |
| 23 | མིག་འདི་ནི་སྲོག་མེད་དེ་རླུང་དང་མཚུངས་སོ། ། | 眼非壽命猶如風， |
| 24 | མིག་འདི་ནི་གང་ཟག་མེད་དེ་ནམ་མཁའ་དང་མཚུངས་སོ། ། | 眼非數取猶如空， |
| 25 | མིག་འདི་ནི་འབྱུང་བ་ཆེན་པོའི་ཀུན་གཞི་ སྟེ་ཡང་དག་པ་མ་ཡིན་པའོ། ། | 眼為不實依藏諸大， |
| 26 | མིག་འདི་ནི་བདག་དང་བདག་གི་དང་བྲལ་བ་སྟེ་སྟོང་པའོ། ། | 是眼為空，離我、我所， |
| 27 | མིག་འདི་ནི་རྩྭ་དང་རྩིག་པ་དང་། ཤིང་དང་། རྡོ་དང་། མིག་ཡོར་ལྟ་བུ་སྟེ་བེམས་པོའོ། ། | 是眼無知，如草木土石， |
| 28 | མིག་འདི་ནི་རླུང་གི་འཁྲུལ་འཁོར་དང་ལྡན་པར་འབྱུང་སྟེ། བྱེད་པ་མེད་པའོ། ། | 是眼無作，機關風轉， |
| 29 | མིག་འདི་ནི་གསོག་སྟེ་ མི་གཙང་བ་དང་རྣག་བསགས་པའོ། ། | 是眼虛假，朽穢所聚， |
| 30 | མིག་འདི་ནི་གསོབ་སྟེ་གཡོག་པ་ཀུན་དུ་མཉེ་བ་གཞིག་པ་རྣམ་པར་འཐོར་བ་འཇིག་པའི་ཆོས་ཅན་ནོ། ། | 是眼浮偽，摧散破壞滅盡之法， |
| 31 | མིག་འདི་ནི་རྟག་ཏུ་རྒ་བའི་ཟིལ་གྱིས་ནོན་པ་སྟེ་ཁྲོན་པ་རྙིང་པ་དང་མཚུངས་སོ། ། | 眼如丘井，常為老逼， |
| 32 | མིག་འདི་ནི་མཐར་འཆི་བ་སྟེ་མཐར་མི་གནས་པའོ། ། | 眼無住際，終歸磨滅。 |
| 33 | ཁྱིམ་ བདག་རྣམས་མིག་ཇི་ལྟ་བ་དེ་བཞིན་དུ་རྣ་བ་དང་སྣ་དང་ལྕེ་དང་ལུས་དང་ཡིད་ཀྱང་རིག་པར་བྱའོ། ། གོང་མ་བཞིན་དུ་སྦྱར་ཏེ་ཆོས་ཐམས་ཅད་ཀྱི་བར་དུ་རིག་པར་བྱའོ། ། | 諸長者！眼為多過，應如是觀，乃至於意、一切諸法，亦復如是。 |
| 34 | ཁྱིམ་བདག་རྣམས་གཞན་ཡང་འདི་ལྟ་སྟེ།  མིག་འདི་དང་འདི་ལྟ་སྟེ། རྣ་བ་དང་སྣ་དང་ལྕེ་དང་ལུས་འདི་ནི་བྱིས་པ་སོ་སོའི་ སྐྱེ་བོ་ཐམས་ཅད་ཀྱི་འདོད་པ་ཙམ་མོ། འདི་ལྟ་སྟེ། ཡིད་འདི་ནི་བྱིས་པ་སོ་སོའི་སྐྱེ་བོ་ཐམས་ཅད་ཀྱི་འདོད་པ་ཙམ་མོ། ། | 復次，諸長者！一切諸法唯有妄欲，異生愚夫不知妄欲故，妄謂是眼、妄謂是耳，乃至妄謂是意。 |
