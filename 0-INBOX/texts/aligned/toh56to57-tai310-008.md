| 5 | འདི་ལྟར་ཤཱ་རིའི་བུ་བྱང་ཆུབ་སེམས་དཔའ་ནི་བཟོད་པ་དང་ལྡན་ཞིང་དང་དུ་ལེན་པའི་ངང་ཚུལ་ཅན་ཡིན་པས། | 舍利子！菩薩摩訶薩由住如是羼底波羅蜜多故，具足忍力， 立性堅正， |
| 6 | གྲང་བ་དང་། ཚ་བ་དང་། བཀྲེས་པ་དང་། [96a.3]སྐོམ་པ་དང་། རླུང་དང་། ཉི་མ་དང་། སྦྲང་བུ་དང་། ཤ་སྦྲང་དང་། སྡིག་སྦྲུལ་གྱིས་རེག་པ་དང་། ངན་དུ་སྨྲ་བ་དང་། ངན་དུ་བརྗོད་པའི་ཚིག་གི་ལམ་ལ་བཟོད་པ་དང་ལྡན་པ་ཡིན་ནོ། ། | 於諸寒熱飢渴、蛇蝎蚊虻、風日等觸志能堪忍，又能忍麁惡言說、鄙陋詞句， |
| 7 | ལུས་ལས་ཚོར་བ་བྱུང་ཞིང་སྐྱེས་པ་སྡུག་བསྔལ་བ་ཤིན་ཏུ་དྲག་པོ་དང་། རྩུབ་པ་དང་། ཚ་བ་དང་། [96a.4]སྲོག་འཕྲོག་པ་དང་། འཆི་བ་ལ་ཐུག་པའི་ཚོར་བ་རྣམས་བཟོད་པ་དང་ཞིང་དང་དུ་ལེན་པའི་ངང་ཚུལ་ཅན་ཡིན་ནོ། ། | 及以依身所起猛迅苦受、堅鞕辛楚、奪命至死，諸如是等所有苦受並能堪忍。 |

| 9 | ཤཱ་རིའི་བུ་ང་མངོན་པར་རྫོགས་པའི་སངས་མ་རྒྱས་པ་ན་བྱང་ཆུབ་སེམས་དཔའི་སྤྱད་པ་སྤྱོད་པའི་ཚེ། ཡུན་རིང་པོར་བཟོད་པ་བསྒོམས་སོ། ། | 復次，舍利子！我昔長夜未成佛時，行菩薩行常修忍辱。」 |
| 10 | བཅོམ་ལྡན་འདས་བྱང་ཆུབ་ [96a.5]སེམས་དཔའ་ཇི་ལྟར་བཟོད་པ་སྒོམ་པར་བགྱིད། | 舍利子白佛言：「世尊！云何世尊為菩薩時，修集忍辱行菩薩行？」 |
| 11 | བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། ཤཱ་རིའི་བུ་ངས་མངོན་པར་ཤེས་པ་འདས་པའི་དུས་ན་བྱང་ཆུབ་སེམས་དཔར་གྱུར་ཏེ། བྱང་ཆུབ་སེམས་དཔའི་སྤྱད་པ་སྤྱོད་པ་ན་སེམས་ཅན་དག་འོངས་ནས་གཤེ་རྒྱ་ཞིང་ཚིག་ངན་པ་དང་། ངག་རྩུབ་ [96a.6]པོའི་ཚིག་སྨྲ་བ་དེ་ལ་ | 佛告舍利子：「我憶過去行菩薩行，多有眾生數來毀罵、非法訶責，面於我前出諸非法弊惡言說。 |
| 12 |  | 舍利子！我於爾時行羼底波羅蜜多故，制伏其心， |
| 13 | ཤཱ་རིའི་བུ་ང་ཁྲོ་བ་དང་། ཞེ་སྡང་བ་དང་། གཏི་མུག་དང་། སེར་སྣས་ཡོངས་སུ་གདུང་བ་མ་སྐྱེས་སོ། ། | 不生忿恚、慳悋、惱熱， |
| 14 | དེ་ལྟར་འཁོར་བར་ཞུགས་པ་ན་འདི་ལྟ་སྟེ།  གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བ་ལྟར་རྙེད་པར་སླ་བ་གང་ཡང་མེད་མོད་ཀྱི། | 但作是念：『於諸行中無有少法是易可得過於毀罵及訶責者， |
| 15 | དེ་ལ་བདག་གིས་བཏང་སྙོམས་སུ་བྱ། | 是故我今應當修捨。 |
| 16 | [96a.7]དེ་ལ་སྙིང་རྗེ་བསྐྱེད་པར་བྱའོ། ། | 又我於彼應起慈悲。 |

| 18 | ཇི་ལྟར་གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བ་ལ་ཕལ་ཆེར་རབ་ཏུ་གནས་པ་དེ་དག་ལས་དེ་འདྲ་བའི་རྣམ་པར་སྨིན་པ་མངོན་པར་འགྲུབ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བ་རྙེད་པར་འགྱུར་རོ། ། | 世間眾生多分安住毀罵、訶責，由斯業故，還復感得如是之相訶毀果報， |
| 19 | གང་དང་གང་དུ་སྐྱེས་པ་ཐམས་ཅད་དུ་ [96b.1]གཟུགས་ངན་པ་དང་། མི་སྡུག་པའི་ལུས་རབ་ཏུ་འཐོབ་བོ། ། | 在在所生常得醜陋可惡之身。 |
| 20 | ང་ནི་གཟུགས་ངན་པར་མི་འདོད། གཤེ་བ་དང་། མི་སྙན་པ་ཟེར་བ་མི་འདོད་དོ། ། | 我今不樂醜陋之事，豈應樂行毀罵訶責？ |
| 21 | དེ་ཅིའི་ཕྱིར་ཞེ་ན། | 何以故？ |
| 22 | འདི་ལྟ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བ་དེ་དག་ནི་མི་རིགས་པའོ། ། | 如是訶毀諸惡業者， |
| 23 | དེ་དག་ནི་མི་རིགས་པའི་ལས་ [96b.2]སོ། ། | 是則名為不相應業、不稱理業、 |
| 24 | དེ་དག་ནི་བྱིས་པའི་ལས་སོ། ། | 愚夫之業， |
| 25 | དེ་དག་ནི་དམན་པའི་ལས་སོ། ། | 是下劣業、 |
| 26 | དེ་དག་ནི་སྐྱེས་བུ་དམ་པ་མ་ཡིན་པའི་ལས་སོ། ། | 非善人業、 |
| 27 | དེ་དག་ནི་མི་བགྲུངས་པའི་ལས་སོ། ། | 非賢聖業。 |
| 28 | འདི་ལྟ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བའི་ཆོས་དེ་ལྟ་བུ་དེ་དག་ནི་སེམས་ཅན་དམྱལ་བར་ལྟུང་བའོ། །འདི་ལྟ་སྟེ། [96b.3]གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བའི་ཆོས་དེ་ལྟ་བུ་དེ་དག་ནི་གཤིན་རྗེའི་འཇིག་རྟེན་དུ་ལྟུང་བའོ། ། | 由此業故，墮於地獄、傍生、焰魔世界， |
| 29 |  | 又由此業與諸惡趣而為眷屬； |
| 30 | འདི་ལྟ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བའི་ཆོས་དེ་ལྟ་བུ་དེ་དག་ནི་སེམས་ཅན་དམྱལ་བའི་གཡོག་བྱེད་པའོ། ། |  |
| 31 | འདི་ལྟ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བའི་ཆོས་དེ་ [96b.4]ལྟ་བུ་དེ་དག་ནི་གནོད་སྦྱིན་དབུལ་པོར་བྱེད་པའོ། ། | 由此業故，感得貧窮藥叉之身， |
| 32 | འདི་ལྟ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བའི་ཆོས་དེ་ལྟ་བུ་དེ་དག་ནི་གནོད་སྦྱིན་དབུལ་པོར་བྱེད་པའི་རྩ་བའོ། ། | 又由此業感貧藥叉根本果報； |
| 33 | འདི་ལྟ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བའི་ཆོས་དེ་ལྟ་བུ་དེ་དག་ནི་ཡི་དགས་དབུལ་པོར་བྱེད་པ་དང་། [96b.5]ཡི་དགས་དབུལ་པོར་བྱེད་པའི་རྩ་བའོ། ། | 由此業故，感得貧窮餓鬼之身，又由此業感貧餓鬼根本果報； |
| 34 | འདི་ལྟ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བའི་ཆོས་དེ་ལྟ་བུ་དེ་དག་ནི་མི་དབུལ་པོར་བྱེད་པ་དང་། མི་དབུལ་པོར་བྱེད་པའི་རྩ་བའོ། ། | 由此業故，感得貧窮人趣之身，又由此業感貧人趣根本果報； |
| 35 | འདི་ལྟ་སྟེ། གཤེ་བ་དང་། མི་སྙན་པར་ཟེར་བའི་ཆོས་དེ་ལྟ་བུ་དེ་དག་ནི་དམན་པའི་འགྲོ་བར་ [96b.6]བྱེད་པ་དང་། དམན་པའི་འགྲོ་བར་བྱེད་པའི་རྩ་བ་སྟེ། | 又由如此訶毀業故，感得下趣及以下趣根本果報。 |
| 36 | ང་ནི་དམན་པའི་འགྲོ་བ་མི་འདོད་དོ། ། | 我今不應求下劣趣。 |
| 37 | དེ་ཅིའི་ཕྱིར་ཞེ་ན། | 所以者何？ |
