| 2 | དེ་ནས་བཅོམ་ལྡན་འདས་ཀྱིས་ལམ་གྱི་བར་དུ་ཁྱིམ་བདག་ལྔ་བརྒྱ་ཙམ་པོ་མི་གཡོ་བའི་གནས་ལ་བཀོད་ནས་ | 爾時世尊於彼中道不移其處，令諸長者建立聖果。 |

| 5 | དེ་ནས་རྒྱལ་པོའི་ཁབ་ཀྱི་གྲོང་ཁྱེར་གྱི་ལྷ་རྣམས་དང་། གནོད་སྦྱིན་ཅི་འཇིགས་འདི་སྙམ་དུ་སེམས་ཏེ། | 時有護王舍城諸天、藥叉、大善神王，名金毘羅，作如是念： |
| 6 | བདག་ཅག་གིས་འདི་ལྟ་བུ་སྦྱིན་གནས་འཇིག་རྟེན་ན་ཤིན་ཏུ་དཀོན་པའི་བཅོམ་ལྡན་འདས་ལ་བསོད་སྙོམས་དབུལ་ལོ་སྙམ་མོ། ། | 「今者如來形相殊異，於世間中最勝難遇，堪受人天之所供養。我等今當應以種種上妙供具奉獻如來。」 |
| 7 | དེ་ནས་གནོད་སྦྱིན་ཅི་འཇིགས་ ཀྱིས་བསོད་སྙོམས་ཁ་དོག་ཕུན་སུམ་ཚོགས་པ། དྲི་ཕུན་སུམ་ཚོགས་པ། རོ་ཕུན་སུམ་ཚོགས་པ། རེག་པ་ཕུན་སུམ་ཚོགས་པ་བཅོམ་ལྡན་འདས་ལ་ཕུལ་ནས་ | 作是念已，便以最勝飲食具足香味成就妙色奉上於佛。 |
| 8 | གནོད་སྦྱིན་ཅི་འཇིགས་ལ་ཐུགས་བརྩེ་བའི་སླད་དུ་བཅོམ་ལྡན་འདས་ཀྱིས་བསོད་སྙོམས་དེ་བཞེས་སོ། ། | 爾時世尊愍其所獻故為納受。 |
| 9 | བཅོམ་ལྡན་འདས་ ལ་གནོད་སྦྱིན་ཅི་འཇིགས་ཀྱིས་བསོད་སྙོམས་ཕུལ་མ་ཐག་ཏུ་དེ་ནས་དེའི་ཚེ་སྟེང་གི་བར་སྣང་ལས་ཅི་འཇིགས་ཀྱི་འཁོར་མང་པོ་གནོད་སྦྱིན་དྲུག་ཁྲི་བརྒྱད་སྟོང་གིས་ལེགས་སོ་ཞེས་བྱ་བ་བྱིན་ཏེ་རྗེས་སུ་ཡི་རང་བའི་སྒྲ་ཕྱུང་ངོ་། ། | 時金毘羅王所領大藥叉眾六萬八千，在虛空中咸生隨喜，以清遠音唱言：「善哉善哉。」 |
| 10 | དེ་ནས་དེའི་ཕྱིར་གནོད་སྦྱིན་ཅི་འཇིགས་ཀྱིས་རང་གི་འཁོར་ རྣམས་ལ་བོས་ཏེ། | 時金毘羅即以此義告其眾曰： |
| 11 | བདག་གིས་ནི་ད་གཟོད་དེ་བཞིན་གཤེགས་པ་ལ་བསོད་སྙོམས་ཕུལ་གྱིས། ཁྱེད་ཀྱིས་ནི་དགེ་སློང་གི་དགེ་འདུན་རྣམས་ལ་ཕུལ་ཅིག ། | 「我已奉佛上妙供具，汝等亦應以諸供養施苾芻僧， |
| 12 | དེ་ནི་ཁྱེད་རྣམས་ཀྱི་ཡུན་རིང་པོའི་དོན་དང་། ཕན་པ་དང་བདེ་བར་འགྱུར་རོ། ། | 當令汝等於長夜中利益安樂。」 |
| 13 | གནོད་སྦྱིན་རྣམས་ཀྱིས་དགེ་སློང་གི་དགེ་ འདུན་ལ་བསོད་སྙོམས་ཕུལ་ནས་ | 諸藥叉眾受王教已，即以上供施苾芻僧。 |
| 14 | གནོད་སྦྱིན་དེ་དག་ལ་སྙིང་བརྩེ་བའི་ཕྱིར་དགེ་སློང་གི་དགེ་འདུན་གྱིས་ཀྱང་བསོད་སྙོམས་བླངས་སོ། ། | 時諸僧眾哀受其供。 |
| 15 | དེ་ནས་བཅོམ་ལྡན་འདས་རྒྱལ་པོའི་ཁབ་ཀྱི་གྲོང་ཁྱེར་ཆེན་པོར་གཤེགས་པ་ལས་དེས་བསོད་སྙོམས་བླངས་པར་མཁྱེན་ནས་ཕྱོགས་དེ་ནས་སླར་ ལོག་གོ ། | _爾時世尊為乞食故入王舍城，既得食已，將還所止。 |
| 16 | དེ་ལྟར་དེའི་ཚེ་ལྷ་སྟོང་ཕྲག་དུ་མ་དང་། ཀླུ་སྟོང་ཕྲག་དུ་མ་དང་། གནོད་སྦྱིན་དང་། དྲི་ཟ་དང་། ལྷ་མ་ཡིན་དང་། ནམ་མཁའ་ལྡིང་དང་། མི་འམ་ཅི་དང་། ལྟོ་འཕྱེ་ཆེན་པོ་སྟོང་ཕྲག་དུ་མ་དང་། མི་དང་མི་མ་ཡིན་པ་སྟོང་ཕྲག་དུ་མ་དང་། སྲོག་ཆགས་བྱེ་བ་ཁྲག་ཁྲིག་བརྒྱ་སྟོང་ ཕྲག་དུ་མ་རྣམས་བཅོམ་ལྡན་འདས་གཤེགས་པའི་ཞབས་འབྲིང་དུ་དོང་ངོ་། ། | 時有無量千眾天、龍、藥叉、健達縛、阿素洛、揭路荼、緊捺洛、牟呼洛伽，及無量千人與非人，又有無量拘胝那庾多百千眾生，隨從佛後。 |
| 17 | དེ་ནས་བཅོམ་ལྡན་འདས་ས་ཕྱོགས་ཡངས་ཤིང་རྒྱ་ཆེ་བ་ཞིག་ཏུ་གཤེགས་ཏེ་བྱོན་ནས་གདན་བཤམས་པ་ལ་བཞུགས་སོ། ། | 爾時如來往彼最勝寬廣之地，敷如常座而坐其上。 |
| 18 | དེ་ནས་གནོད་སྦྱིན་ཅི་འཇིགས་འཁོར་དང་བཅས་པས་ལྷའི་མེ་ཏོག་ མན་དཱ་ར་དང་། ཨུད་པ་ལ་དང་། པད་མ་དང་། ཀུ་མུ་ད་དང་། པད་མ་དཀར་པོ་དང་། ལྷའི་ཙན་དན་གྱི་ཕྱེ་མ་བླངས་ཏེ་བཅོམ་ལྡན་འདས་ལ་མཆོད་པ་བྱ་བའི་ཕྱིར་བཅོམ་ལྡན་འདས་ལ་གཏོར། | 時金毘羅與其部從，即持種種天曼陀羅花、殟鉢羅花、鉢特摩花、拘貿陀花、奔荼利花，復持種種天旃檀末諸供養具，而散於佛， |
| 19 | མངོན་པར་གཏོར། མངོན་པར་རབ་ཏུ་གཏོར་ཏོ། ། གཏོར་མངོན་པར་གཏོར། མངོན་པར་རབ་ཏུ་གཏོར་ནས་ཐལ་མོ་སྦྱར་ཏེ་ཕྱག་འཚལ་ནས་བཅོམ་ལྡན་འདས་ཀྱི་སྤྱན་སྔར་འདུག་གོ ། | 所謂勝散、大勝散、妙散、大妙散。作如是等慇懃散已，合掌佛前禮敬而住。 |
| 20 | དེ་ནས་བཅོམ་ལྡན་འདས་ཀྱིས་གནོད་སྦྱིན་ཅི་འཇིགས་ཀྱི་བསམ་པ་ཡང་མཁྱེན། དེའི་འཁོར་གནོད་སྦྱིན་མང་པོའི་བསམ་པ་ཡང་མཁྱེན་ནས་འཛུམ་པ་མཛད་དོ། ། | _爾時如來知金毘羅及其大眾心之所念，即便微笑。 |
| 21 | ཆོས་ ཉིད་ནི་འདི་ཡིན་ཏེ།  ནམ་སངས་རྒྱས་བཅོམ་ལྡན་འདས་རྣམས་འཛུམ་པ་མཛད་པ་དེ་ན་ཞལ་གྱི་སྒོ་ནས་འོད་ཟེར་ཁ་དོག་དུ་མ་ཁ་དོག་སྣ་ཚོགས་འདི་ལྟ་སྟེ། | 諸佛常法，現微笑時，從其面門出種種無量色光， |
| 22 | སྔོན་པོ་དང་། སེར་པོ་དང་། དམར་པོ་དང་། དཀར་པོ་དང་། ལེ་བརྒན་དང་། ཤེལ་དང་། དངུལ་གྱི་ཁ་དོག་ལྟ་བུ་བྱུང་སྟེ། | 所謂青、黃、赤、白、紅色、銀色及水精色， |
| 23 | དེས་འཇིག་རྟེན་གྱི་ཁམས་མཐའ་ཡས་མུ་མེད་པ་སྣང་བས་ཁྱབ་པར་བྱས་ནས་ཉི་མ་དང་ཟླ་བའི་གཟི་བརྗིད་མེད་པར་བྱས་ཏེ། | 其光遍照無量無邊一切世界，日月威光掩蔽不現， |
| 24 | སེམས་ཅན་དམྱལ་བ་པའི་སེམས་ཅན་ནས་ཚངས་པའི་འཇིག་རྟེན་གྱི་བར་དུ་མངོན་པར་འཕགས་ཏེ། | 下照地獄令彼悅樂，乃至上踊至於梵世。 |
| 25 | སླར་ལོག་ནས་བཅོམ་ལྡན་འདས་ལ་ལན་བདུན་བསྐོར་ བ་བྱས་ཏེ། | 所應作已而復還來，右繞七匝， |
