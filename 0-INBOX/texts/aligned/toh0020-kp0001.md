# Twenty-five Aspects Great Vehicle Sutra — aligned

| # | toh0020-kp0001-bo | toh0020-kp0001-zh |
|---|---|---|
| 1 | ༄༅༅། །རྒྱ་གར་སྐད་དུ། ཨཱརྱ་པཉྩ་བིངྴ་ཏི་ཀ་པྲཛྙཱ་པཱ་ར་མི་ཏཱ་མུ་ཁ་ནཱ་མ་མ་ཧཱ་ཡཱ་ན་སཱུ་ཏྲ། བོད་སྐད་དུ། |  |
| 2 | འཕགས་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོ་ཉི་ཤུ་རྩ་ལྔ་པ་ཞེས་བྱ་བ་ཐེག་པ་ཆེན་པོའི་མདོ། | 聖般若波羅蜜多二十五門大乘經 |
| 3 | སངས་རྒྱས་དང་། བྱང་ཆུབ་སེམས་དཔའ་ཐམས་ཅད་ལ་ཕྱག་འཚལ་ལོ། ། | 頂禮一切佛菩薩。 |
| 4 | འདི་སྐད་བདག་གིས་ཐོས་པ་དུས་གཅིག་ན། | 如是我聞：一時， |
| 5 | བཅོམ་ལྡན་འདས་རི་རབ་ཀྱི་ཟོམ་ལ་ལྷ་ཐམས་ཅད་ཀྱི་མཚན་མོའི་གནས་ན་ | 世尊在須彌山頂諸天夜居處， |
| 6 | བྱང་ཆུབ་སེམས་དཔའ་བྱེ་བ་ཁྲག་ཁྲིག་འབུམ་ཕྲག་དུ་མ་དང་ཐབས་ཅིག་ཏུ་བཞུགས་ཏེ། | 與無量百千萬億菩薩俱。 |
| 7 | དེ་ནས་བཅོམ་ལྡན་འདས་ལྷ་དང་། ལྷའི་བུ་དང་། ལྷ་མ་ཡིན་དང་། རླུང་ལྷ་དང་། ནམ་མཁའ་ལྡིང་དང་། ཀླུ་དང་། གནོད་སྦྱིན་དང་། མིའམ་ཅི་དང་། སྲིན་པོ་དང་། རིག་སྔགས་འཆང་ཐམས་ཅད་དང་། འབྱུང་པོ་དང་། ལོག་འདྲེན་དང་། ཤ་ཟ་དང་། སྣང་བ་དང་། མི་སྣང་བའི་མ་མོའི་ཚོགས་ཤིན་ཏུ་མང་ཞིང་རྒྱ་ཆེ་བ་དཔག་ཚད་ལྔའི་དཀྱིལ་འཁོར་དུ་འདུས་པ་ཤ་སྟག་དང་། | 爾時一切諸天、天子、阿修羅、風神、迦樓羅、龍、夜叉、緊那羅、羅剎、持明咒者[^1]，及諸部多、邪師、畢舍遮、有形無形鬼母大眾等，極多甚廣，悉皆集會於此五百由旬道場； |
| 8 | དགེ་སློང་སྟོང་ཉིས་བརྒྱ་ལྔ་བཅུས་བསྐོར་ཅིང་མདུན་དུ་བདར་ནས་ཆོས་སྟོན་ཏོ། ། | 亦有比丘千二百五十人，周匝圍遶，列坐於前。［世尊］即為說法。 |
| 9 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་ལག་ན་རྡོ་རྗེ་རྡོ་རྗེའི་རིགས་ཐམས་ཅད་ཀྱིས་ཡོངས་སུ་བསྐོར་ཅིང་། | 爾時金剛手菩薩摩訶薩為一切金剛部大眾圍遶， |
| 10 | རིག་པའི་ཚོགས་དང་། ཕྱག་རྒྱའི་ཚོགས་དེ་དག་ཐམས་ཅད་དང་། རིག་སྔགས་འཆང་བྱེ་བ་ཕྲག་དུ་མས་ཡོངས་སུ་བསྐོར་ནས་ | 復為明者眾[^2]、手印眾及多俱胝持明咒者周匝圍遶， |
| 11 | བཅོམ་ལྡན་འདས་ག་ལ་བ་དེར་སོང་སྟེ་ཕྱིན་ནས། | 往詣世尊所， |
| 12 | བར་སྣང་ལས་བབས་ནས་བཅོམ་ལྡན་འདས་ཀྱི་ཞབས་ལ་མགོ་བོས་ཕྱག་འཚལ་ཏེ། | 從空中下，禮世尊足， |
| 13 | བཅོམ་ལྡན་འདས་ལ་ལན་གསུམ་བསྐོར་བ་བྱས་ནས། ཕྱོགས་གཅིག་ཏུ་འདུག་པ་དང་། | 遶佛三匝，卻坐一面。 |
| 14 | དེ་ནས་བཅོམ་ལྡན་འདས་ཀྱིས་གསང་བའི་བདག་པོ་ཆེན་པོ་ལག་ན་རྡོ་རྗེ་ལ་བཀའ་པ། | 爾時世尊告大祕密主金剛手曰： |
| 15 | གསང་བ་པའི་བདག་པོ་ཉི་ཤུ་རྩ་ལྔ་པོ་འདི་དག་ནི་ངའི་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོ་ཡིན་ནོ། ། | 「祕密主！此等二十五法，是我之般若波羅蜜多門。 |
| 16 | སངས་རྒྱས་དང་། བྱང་ཆུབ་སེམས་དཔའ་ཐམས་ཅད་ལ་ཕྱག་འཚལ་ལོ། ། | 「頂禮一切佛菩薩。 |
| 17 | ཨོཾ་བྱང་ཆུབ་ཀྱི་སེམས་ཀྱི་རྡོ་རྗེ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡（Oṃ），菩提心金剛是般若波羅蜜多門； |
| 18 | ཨོཾ་ཀུན་ཏུ་བཟང་པོའི་སྤྱོད་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，普賢行是般若波羅蜜多門； |
| 19 | ཨོཾ་ཡིད་བཞིན་གྱི་ནོར་བུ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，如意寶是般若波羅蜜多門； |
| 20 | ཨོཾ་འགོག་པ་མེད་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，無滅是般若波羅蜜多門； |
| 21 | ཨོཾ་སྐྱེ་བར་འགྱུར་བ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，當生是般若波羅蜜多門； |
| 22 | ཨོཾ་རྣམ་པར་ཤེས་པ་ཐམས་ཅད་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，一切識是般若波羅蜜多門； |
| 23 | ཨོཾ་འབར་བ་ཆེན་པོའི་ཆོས་ཉིད་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，大燄[^3]法性是般若波羅蜜多門； |
| 24 | ཨོཾ་བརྩོན་འགྲུས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，精進是般若波羅蜜多門； |
| 25 | ཨོཾ་ཐམས་ཅད་དུ་འགྲོ་བ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，遍行一切是般若波羅蜜多門； |
| 26 | ཨོཾ་རྡོ་རྗེ་ཐམས་ཅད་བརྟན་པའི་སེམས་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，金剛一切堅固[^4]心是般若波羅蜜多門； |
| 27 | ཨོཾ་དེ་བཞིན་གཤེགས་པ་ཐམས་ཅད་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，一切如來是般若波羅蜜多門； |
| 28 | ཨོཾ་རང་བཞིན་རྣམ་པར་དག་པའི་ཆོས་ཉིད་ཡེ་ཤེས་རྣམ་པར་དག་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，自性清淨之清淨法性智是般若波羅蜜多門； |
| 29 | ཨོཾ་ལས་རྣམ་པར་སྦྱོང་བ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，淨治業是般若波羅蜜多門； |
| 30 | ཨོཾ་ངེས་པར་གནོད་མཛེས་རྡོ་རྗེ་ཅན་ཕཊ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，決定妙害具金剛之『泮吒』（phaṭ）字是般若波羅蜜多門； |
| 31 | ཨོཾ་འདོད་པ་ལ་འདོད་ཆགས་རྣམ་པར་དག་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，欲貪清淨是般若波羅蜜多門； |
| 32 | ཨོཾ་མགྱོགས་པའི་རྡོ་རྗེ་ཅན་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，迅疾金剛是般若波羅蜜多門； |
| 33 | ཨོཾ་ཧཱུྃ་ཐམས་ཅད་དུ་འགྲོ་བ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，『吽』（hūṃ）行於一切是般若波羅蜜多門； |
| 34 | ཨོཾ་ཧྲཱིཿཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，『醯唎』（hrīh）是般若波羅蜜多門； |
| 35 | ཨོཾ་ཨ་ཞེས་བྱ་བའི་སྒོ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，『阿』（a）字門是般若波羅蜜多門； |
| 36 | ཨོཾ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，般若波羅蜜多是般若波羅蜜多門； |
| 37 | ཨོཾ་ཨྃ་བ་ཧཱུྃ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་པའི་སྒོའོ། ། | 嗡，『暗縛吽』（aṃ va hūṃ）是般若波羅蜜多門； |
