# The Noble Mahayana Sutra of Dependent Origination — aligned

| # | toh0212-bo | toh0212-zh |
|---|---|---|
| 1 | སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་ཐམས་ཅད་ལ་ཕྱག་འཚལ་ལོ། ། | 敬禮一切佛菩薩。 |
| 2 | འདི་སྐད་བདག་གིས་ཐོས་པ་དུས་གཅིག་ན། | 如是我聞：一時， |
| 3 | བཅོམ་ལྡན་འདས་སུམ་ཅུ་རྩ་གསུམ་གྱི་ལྷའི་ནང་ན། ཨར་མོ་ནིག་ལྟ་བུའི་རྡོ་ལེབ་ལ | 世尊在三十三天般荼劍婆羅石， |
| 4 | རྟ་ཐུལ་ལ་སོགས་པ་ཉན་ཐོས་ཆེན་པོ་རྣམས་དང་། | 與馬勝比丘等諸大聲聞、 |
| 5 | འཕགས་པ་བྱམས་པ་དང | 聖彌勒、 |
| 6 | འཕགས་པ་སྤྱན་རས་གཟིགས་དབང་ཕྱུག་དང་། | 聖觀自在、 |
| 7 | ལག་ན་རྡོ་རྗེ་ལ་སོགས་པ་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་ཡོན་ཏན་རིན་པོ་ཆེ་དཔག་ཏུ་མེད་པས་བརྒྱན་པ་རྣམས་དང་། | 金剛手等菩薩摩訶薩俱。此諸菩薩，皆以無量功德寶而為莊嚴。 |
| 8 | མི་མཇེད་ཀྱི་བདག་པོ་ཚངས་པ་ཆེན་པོ་དང་། | 復與娑婆世界主大梵天王、 |
| 9 | སྲེད་མེད་ཀྱི་བུ་དང་། | 那羅延天、 |
| 10 | དབང་ཕྱུག་ཆེན་པོ་ལ་སོགས་པ་ལྷ་རྣམས་དང་། | 大自在天等諸天、 |
| 11 | ལྷའི་དབང་པོ་བརྒྱ་བྱིན་དང་། | 天主帝釋天、 |
| 12 | དྲི་ཟའི་རྒྱལ་པོ་གཙུག་ཕུད་ལྔ་པ་དང་ཐབས་ཅིག་ཏུ་བཞུགས་ཏེ། | 乾闥婆王波遮旬俱。 |
| 13 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་སྤྱན་རས་གཟིགས་དབང་ཕྱུག་སྟན་ལས་ལངས་ཏེ། | 爾時，觀自在菩薩摩訶薩從座而起， |
| 14 | བླ་གོས་ཕྲག་པ་གཅིག་ཏུ་གཟར་ནས། | 偏袒右肩， |
| 15 | པུས་མོ་གཡས་པའི་ལྷ་ང་རི་རབ་ཀྱི་རྩེ་མོ་ལ་བཙུགས་ཏེ། | 右膝著於須彌山頂， |
| 16 | བཅོམ་ལྡན་འདས་ག་ལ་བ་དེ་ལོགས་སུ་ | 向世尊處， |
| 17 | ཐལ་མོ་སྦྱར་བ་བཏུད་ནས་ | 合掌作禮， |
| 18 | བཅོམ་ལྡན་འདས་ལ་འདི་སྐད་ཅེས་གསོལ་ཏོ། ། | 白世尊言： |
| 19 | བཅོམ་ལྡན་འདས་ལྷ་འདི་དག་ནི་མཆོད་རྟེན་བགྱིད་པར་འཚལ་བ་ཤ་སྟག་སྟེ། | 「世尊！此等諸天欲請造塔[之法]， |
| 20 | འཁོར་གྱི་དཀྱིལ་འཁོར་འདིར་མཆིས་ན། | 故來此會， |
| 21 | ཅི་ནས་ཚངས་པའི་བསོད་ནམས་འཕེལ་བ་དང་། | 彼等云何能生梵福？ |
| 22 | ལྷ་དང་བཅས་པ་བདུད་དང་བཅས་པ། ཚངས་པ་དང་བཅས་པའི་འཇིག་རྟེན་ན་དགེ་སྦྱོང་དང་བྲམ་ཟེར་བཅས་པའི་སྐྱེ་དགུ་ལས་དགེ་སློང་དང་། དགེ་སློང་མ་དང་། དགེ་བསྙེན་དང་། དགེ་བསྙེན་མ་དག་བསོད་ནམས་ཤིན་ཏུ་མང་དུ་འཕེལ་བར་འགྱུར་བ་དེ་ལྟ་དེ་ལྟར། | 若比丘、比丘尼、優婆塞、優婆夷，比於沙門、梵志及餘眾生、諸天、魔、梵及餘世間，云何增長多福？ |
| 23 | བཅོམ་ལྡན་འདས་ཀྱིས་དེ་དག་ལ་ཆོས་བསྟན་དུ་གསོལ། | 唯願世尊，為彼等說。」 |
| 24 | དེ་ནས་བཅོམ་ལྡན་འདས་ཀྱིས་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བའི་ཚིགས་སུ་བཅད་པ་བཀའ་སྩལ་པ། | 爾時，世尊即說緣起偈： |
| 25 | ཡེ་དྷརྨཱ་ཧེ་ཏུ་པྲ་བྷ་བཱ་ཧེ་ཏུན་ཏེ་ཥཱན་ཏ་ཐཱ་ག་ཏོ་ཧྱ་བ་དཏ། ཏེ་ཥཱཉྩ་ཡོ་ནི་རོ་དྷ་ཨེ་བམ་བཱ་དཱི་མ་ཧཱ་ཤྲ་མ་ཎཿ། | "曳 達磨 醯睹般薄婆 醯噸 低商 多陀伽都 希阿婆達 低商 遮 瑜 尼盧達 醫凡婆地 摩訶室羅摩拏" |
| 26 | ཆོས་གང་རྒྱུ་བྱུང་དེ་དག་གི། རྒྱུ་དང་དེ་འགོག་གང་ཡིན་པའང་།། དེ་བཞིན་གཤེགས་པས་བཀའ་སྩལ་ཏེ།། དགེ་སྦྱོང་ཆེན་པོས་དེ་སྐད་གསུངས།། | "諸法從緣起，緣盡法亦滅，如來大沙門，常作如是說。" |
| 27 | སྤྱན་རས་གཟིགས་དབང་ཕྱུག་འདི་ལྟ་སྟེ། | 「觀自在！ |
| 28 | རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་འདི་ནི་ | 此緣起者， |
| 29 | དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱི་ཆོས་ཀྱི་སྐུ་ཡིན་ཏེ། | 即諸如來法身。 |
| 30 | སུས་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་མཐོང་བ་དེས། | 何人見緣起， |
| 31 | དེ་བཞིན་གཤེགས་པ་མཐོང་ངོ་། | 彼即見如來。 |
| 32 | །སྤྱན་རས་གཟིགས་དབང་ཕྱུག་ | 觀自在！ |
| 33 | རིགས་ཀྱི་བུའམ། རིགས་ཀྱི་བུ་མོ་དད་པ་ཅན་གང་ལ་ལ་ཞིག་གིས་ | 若善男子、善女人，信心具足， |
| 34 | མི་གནས་པའི་ཕྱོགས་སུ་ | 於未有[塔]處， |
| 35 | མཆོད་རྟེན་ནི་སྐྱུ་རུ་རའི་འབྲུ་ཙམ། | 而能造塔，小至如菴摩羅果許， |
| 36 | སྲོག་ཤིང་ནི་ཁབ་ཙམ། | 塔剎則如針許、 |
| 37 | གདུགས་ནི་བ་ཀུ་ལའི་མེ་ཏོག་ཙམ་ཞིག་བྱས་ལ། | 露盤如末俱羅華許， |
| 38 | རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་ཆོས་ཀྱི་དབྱིངས་ཀྱི་ཚིགས་སུ་བཅད་པ་ནང་དུ་བཅུག་ན་ | 內置法界緣起偈， |
| 39 | དེ་ཚངས་པའི་བསོད་ནམས་བསྐྱེད་པར་འགྱུར་ཏེ། | 是人將生梵福。 |
| 40 | འདི་ནས་ཤི་འཕོས་ཤིང་འཆི་བའི་དུས་བྱས་ནས་ | 命終之後， |
| 41 | ཚངས་པའི་འཇིག་རྟེན་དག་ཏུ་སྐྱེ་བར་འགྱུར་རོ།། | 當生梵世； |
| 42 | དེ་ནས་ཤི་འཕོས་ཏེ་འཆི་བའི་དུས་བྱས་ནས་ | 於彼命終， |
| 43 | གནས་གཙང་མའི་རིས་ཀྱི་ལྷ་རྣམས་དང་སྐལ་བ་མཉམ་པར་སྐྱེ་བར་འགྱུར་རོ། ། | 當生淨居天，福分與彼諸天等無有異。」 |
| 44 | བཅོམ་ལྡན་འདས་ཀྱིས་དེ་སྐད་ཅེས་བཀའ་སྩལ་ནས། | 世尊說是語已， |
| 45 | ཉན་ཐོས་དེ་དག་དང་། | 諸聲聞、 |
| 46 | བྱང་ཆུབ་སེམས་དཔའ་དེ་དག་དང་། | 菩薩、 |
| 47 | ཐམས་ཅད་དང་ལྡན་པའི་འཁོར་དེ་དག་དང་། | 一切眷屬， |
| 48 | ལྷ་དང་། མི་དང་། ལྷ་མ་ཡིན་དང་། དྲི་ཟར་བཅས་པའི་འཇིག་རྟེན་ཡི་རངས་ཏེ། | 及諸世間天、人、阿修羅、乾闥婆等，皆大歡喜， |
| 49 | བཅོམ་ལྡན་འདས་ཀྱིས་གསུངས་པ་ལ་མངོན་པར་བསྟོད་དོ། ། | 於世尊所說，稱揚讚嘆。 |
| 50 | འཕགས་པ་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་ཞེས་བྱ་བ་ཐེག་པ་ཆེན་པོའི་མདོ་རྫོགས་སོ།། །། | 聖緣起大乘經 |
| 51 | རྒྱ་གར་གྱི་མཁན་པོ་སུ་རེན་བྡྲོ་དྷི་དང་། | 印度和尚天主覺、 |
| 52 | ཞུ་ཆེན་གྱི་ལོཙྪ་བ་བན་དེ་ཡེ་ཤེས་སྡེས་བསྒྱུར་ཅིང་ཞུས་ཏེ་གཏན་ལ་ཕབ་པ།། །། | 主校譯師佛僧耶謝德翻譯、抉擇。 |
