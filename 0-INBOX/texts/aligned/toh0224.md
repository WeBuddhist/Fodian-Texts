# The Noble Mahayana Sutra on the Chapter of Firm Superior Aspiration — aligned

| # | toh0224-bo | toh0224-zh |
|---|---|---|
| 1 | སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་ཐམས་ཅད་ལ་ཕྱག་འཚལ་ལོ། ། | 頂禮一切佛菩薩。 |
| 2 | འདི་སྐད་བདག་གིས་ཐོས་པ་དུས་གཅིག་ན། | 如是我聞：一時， |
| 3 | བཅོམ་ལྡན་འདས་རྒྱལ་པོའི་ཁབ་ན་བྱ་རྒོད་ཀྱི་ཕུང་པོའི་རི་ལ། | 世尊在王舍城靈鷲山中， |
| 4 | དགེ་སློང་སྟོང་ཉིས་བརྒྱ་ལྔ་བཅུའི་དགེ་སློང་གི་དགེ་འདུན་ཆེན་པོ་དང་། | 與大比丘僧千二百五十人、 |
| 5 | བྱང་ཆུབ་སེམས་དཔའ་ལྔ་བརྒྱ་ཙམ་དང་ཐབས་ཅིག་ཏུ་བཞུགས་སོ། ། | 菩薩五百人俱。 |
| 6 | དེའི་ཚེ་བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པ་ནང་པར་ | 爾時，堅勝意樂菩薩清旦而起， |
| 7 | སྔར་ཤམ་ཐབས་དང་། | 著裙、 |
| 8 | ཆོས་གོས་བགོས། | 搭衣、 |
| 9 | ལྷུང་བཟེད་ཐོགས་ཏེ་ | 持鉢， |
| 10 | རྒྱལ་པོའི་ཁབ་ཏུ་བསོད་སྙོམས་ལ་སོང་ངོ་། ། | 入王舍大城乞食。 |
| 11 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པ་བསོད་སྙོམས་ཀྱི་ཕྱིར་རྒྱལ་པོའི་ཁབ་ཀྱི་གྲོང་ཁྱེར་ཆེན་པོར་མཐར་ཆགས་སུ་རྒྱུ་བ་ན། | 爾時，菩薩次第而行， |
| 12 | ཚོང་དཔོན་ཞིག་གི་ཁྱིམ་ན་བུ་མོ་གཟུགས་བཟང་བ་མཛེས་པ། བལྟ་ན་སྡུག་པ། ཁ་དོག་བཟང་པོ་རྒྱས་པ་མཆོག་དང་ལྡན་པ་ཞིག་ཡོད་པ་མཐོང་ངོ་། ། | 至一長者舍。長者有女，形色妙好，韶麗可愛，端正姝好，色相第一。 |
| 13 | དེས་བུ་མོ་དེ་མཐོང་ནས་ | ［菩薩］見彼女已， |
| 14 | འདོད་ཆགས་ཀྱིས་ཡོངས་སུ་གདུང་བ་སྐྱེས་ཏེ། | 心生貪欲，極受熱惱， |
| 15 | དེས་མི་སྡུག་པ་ཡིད་ལ་བྱའོ་སྙམ་དུ་བསམས་ཀྱང་དེའི་སེམས་སྡུག་པའི་མཚན་མ་འབའ་ཞིག་གིས་ཡོངས་སུ་ཟིན་ཏེ་འདུག་པར་གྱུར་ཏོ། ། | 是故雖作是念：「我當作意，念不淨觀。」，然心仍一向執受可愛之相。 |
| 16 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པ་དགའ་བར་འཛིན་པའི་སེམས་ཀྱིས་ | 由是心執愛樂故， |
| 17 | ཁྱིམ་དེ་ནས་བསོད་སྙོམས་མ་བླངས་པར་ | 乃未受食， |
| 18 | རྒྱལ་པོའི་ཁབ་ཀྱི་གྲོང་ཁྱེར་ནས་ལྷུང་བཟེད་སྟོང་བཞིན་དུ་ཕྱིར་སོང་སྟེ། | 空鉢出王舍城； |
| 19 | འདོད་པའི་རྟོག་པ་དེ་ཡིད་ལ་མི་བྱ་བར་བྱ་བའི་ཕྱིར་ | 為令心於欲念無所作意， |
| 20 | འབད་ན་སོ་སོར་བརྟག་པའི་སྟོབས་ཀྱིས་ | 精勤分別觀察， |
| 21 | ཀྱང་འདོད་པའི་རྟོག་པ་བསལ་མ་ནུས་ནས། | 然於欲念，力未能除。爾時， |
| 22 | བཅོམ་ལྡན་འདས་ཀྱིས་ལྷའི་སྤྱན་རྣམ་པར་དག་པ་མིའི་ལས་འདས་པས་ | 世尊清淨天眼，過於人眼， |
| 23 | བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པའི་འདོད་པའི་རྟོག་པ་དང་ལྡན་པ་ | 觀見堅勝意樂菩薩心生貪欲， |
| 24 | སོ་སོར་རྟོག་པའི་སྟོབས་ཀྱིས་ཀྱང་ | 雖觀察思惟， |
| 25 | འདོད་པའི་རྟོག་པ་བསལ་མ་ནུས་པ་གཟིགས་སོ། | 然於欲念，力未能除。 |
| 26 | དེ་ནས་བཅོམ་ལྡན་འདས་ཀྱིས་བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པ་གདུལ་བར་བྱ་བའི་དབང་གི་ཕྱིར་ | 爾時，世尊為調伏堅勝意樂菩薩， |
| 27 | བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པ་ལམ་གང་ནས་འགྲོ་བའི་ལམ་དེར་ཚོང་དཔོན་གྱི་བུ་མོ་དེ་ཅི་འདྲ་བ་དེ་འདྲ་བའི་བུ་མོ་ཞིག་སྤྲུལ་ནས་ | 乃於菩薩還歸之道，化現一女，形貌一如彼長者女。 |
| 28 | བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པས་སྤྲུལ་པའི་བུ་མོ་དེ་མཐོང་ངོ་། ། | 堅勝意樂菩薩見是變化女， |
| 29 | མཐོང་ནས་ཀྱང་འདི་སྐད་ཅེས་སྨྲས་སོ། ། | 即問言曰： |
| 30 | རིགས་ཀྱི་བུ་མོ་ཁྱོད་གར་འགྲོ། ། | 「善女人！汝欲何往？。」 |
| 31 | སྤྲུལ་པའི་བུ་མོས་སྨྲས་པ། | 變化女告言： |
| 32 | ཁྱོད་གར་བཞུད་པ་དེར་བདག་མཆིའོ། ། | 「汝住何處，我即往之。」 |
| 33 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པ་འཇིགས་ཤིང་སྐྲག་ནས་བྲོས་སོ། །བྲོས་ནས་རི་བགྲོད་དཀའ་བ་ཞིག་ཏུ་སོང་ངོ་། ། | 菩薩即生恐畏，逃走遠避，入一山中，其地難至。 |
| 34 | སྤྲུལ་པའི་བུ་མོ་དེ་ཡང་རི་བགྲོད་དཀའ་བ་དེ་ཉིད་དུ་སོང་ངོ་། ། | 變化女亦隨往赴。 |
| 35 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པ་ལུས་ངལ་ཆད་དེ་འདུག་གོ། ། | 爾時，堅勝意樂菩薩身體疲懈而坐。 |
| 36 | སྤྲུལ་པའི་བུ་མོ་དེ་ཡང་བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པའི་མདུན་དུ་འདུག་གོ། ། | 變化女亦隨趁菩薩前， |
| 37 | འདུག་ནས་ཀྱང་ཚིགས་སུ་བཅད་པ་འདི་སྐད་ཅེས་སྨྲས་སོ། ། | 坐已，說是偈言： |
| 38 | "བདག་ནི་སེམས་ཀྱིས་སྤང་བར་གྱིས། །ལུས་ནི་བྲོས་པས་ཅི་ཞིག་བྱ། །བརྟན་པོ་ལུས་ནི་བྲོས་པ་ཡིས། །འདོད་ཆགས་སྤོང་བར་མི་འགྱུར་རོ། །" | 「當以心斷我，身逃有何益？堅固身雖逃，不能斷貪欲。」 |
| 39 | དེ་ནས་སྤྲུལ་པའི་བུ་མོ་དེས་ཚིགས་སུ་བཅད་པ་དེ་སྐད་ཅེས་སྨྲས་ནས་ | 變化女說是偈已， |
| 40 | རི་བགྲོད་དཀའ་བ་དེ་ལས་ལྷུང་ངོ་། ། | 即從彼山墜墮。 |
| 41 | ལྷུང་ནས་དེའི་མགོ་ཡང་ལོགས་ཤིག་ཏུ་སོང་ངོ་། །ལག་པ་ཡང་ལོགས་ཤིག །རྐང་པ་ཡང་ལོགས་ཤིག །ཡན་ལག་དང་ཉིང་ལག་རྣམས་ཀྱང་ལོགས་ཤིག་ཏུ་སོང་སྟེ། | 墮已，其頭手足及諸肢節，各散異處。 |
| 42 | འདི་ལྟ་སྟེ་དཔེར་ན་ཁ་བ་བཅངས་པ་ལས་རབ་ཏུ་དྲོས་ཤིང་རབ་ཏུ་ཞུ་ནས་ས་ལ་ཐིམ་པ་དེ་བཞིན་དུ་ | 既而如掬冰雪，遇熱盡融，滲沒土中， |
| 43 | སྤྲུལ་པའི་བུ་མོ་དེ། དེ་ཉིད་དུ་མི་སྣང་བར་གྱུར་ཏོ། ། | 彼變化女即忽不見。 |
| 44 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་ལྷག་པའི་བསམ་པ་བརྟན་པས། སྤྲུལ་པའི་བུ་མོ་དེ་མ་མཐོང་ནས་ | 堅勝意樂菩薩不見變化女， |
| 45 | འདོད་ཆགས་ཀྱི་སེམས་དེ་ཉིད་ཞི་བར་གྱུར་ཏེ། | 貪欲之心便即止息， |
| 46 | དེ་སྐྱོ་བ་ཆེན་པོ་སྐྱེས་སོ། ། | 復極沮悴。 |
| 47 | དེས་སྐྱོ་བ་ཆེན་པོ་ཐོབ་སྟེ། སྤྲུལ་པས་ཚིགས་སུ་བཅད་པ་སྨྲས་པ་དེ་མངོན་སུམ་དུ་གྱུར་ནས་ | 彼時 ，變化女所說偈言於是現前， |
