| 193 | ཡན་ལག་ཉིང་ལག་བཅད་ཀྱང་དགྲ་ལ་བཟོད། ། | _假使碎身苦，_於怨大忍生。 |
| 194 | བརྩོན་འགྲུས་ཀྱི་ནི་ཕ་རོལ་ཕྱིན་སྤྱོད་ཅིང་། ། | _正勤波羅蜜，_修行極疲苦， |
| 195 | སངས་རྒྱས་སྐུ་ལ་སྨོན་ པས་ཡོངས་མི་སྐྱོ། ། | _發弘大誓願，_求常住佛身。 |
| 196 | ཤེས་རབ་ཐབས་དགའ་རྒྱ་ཆེན་བསམ་གཏན་པ། །བསམ་གཏན་སྤྱོད་ཡུལ་དགའ་རྒྱལ་རྣམ་པར་ལྟ། ། | _樂觀諸定境，_樂廣慧方便， |
| 197 | ཆོས་དབྱིངས་དམ་པ་བདེ་བར་གཤེགས་པའི་སྐུ། །དེ་འདྲར་བདག་གྱུར་ཅེས་ནི་དེ་ལ་སྨོན། ། | _樂觀於法界，_願等法界身。 |
| 198 | སྲིད་པར་འགྲོ་བ་དག་ཏུ་དགེ་བྱེད་ཅིང་། ། | _於佛行善已， |
| 199 | མི་མཆོག་གིས་ནི་བྱང་ཆུབ་མཚུངས་མེད་ཐོབ། ། | _成無等妙覺， |
| 200 | དག་པ་ དྲི་མེད་གཙང་ཞིང་རྡུལ་བྲལ་བ། ། | {_清白離塵染。} |
| 201 | ནམ་མཁའ་འདྲ་བ་ཡངས་པའི་སྐུ་ཐོབ་བོ། ། | _獲大虛空身， |
| 202 | རང་བཞིན་སྟོང་སྟེ་བདག་དང་སེམས་ཅན་བྲལ། ། | _無我人性空， |
| 203 | མཚན་མ་མེད་ཅིང་སྒྲ་དང་བྲལ་བ་ཐོབ། ། | _無相不可說， |
| 204 | མིག་གི་ཡུལ་ཀུན་ལས་ནི་རབ་འདས་པ། ། | {}_過諸眼境界。 |
| 205 | དེ་འདྲའི་སྐུ་ནི་ཐུབ་པས་ཡང་དག་ཐོབ། ། | {_證是牟尼身，} |
| 206 | གཟོད་མ་ནས་སྟོང་མ་བྱས་མ་བྱུང་བ། ། | {_本空無起作，} |
| 207 | གཟུགས་ དང་སྒྲ་བྲལ་ཡིད་ཀྱང་རྣམ་དག་པ། ། | _意淨離色聲， |
| 208 | དེ་བཞིན་གཤེགས་སྐུ་མི་གཡོ་གང་མཐོང་བ། ། | _見真如身者， |
| 209 | དེས་ནི་ཕྱོགས་བཅུའི་བདེ་བར་གཤེགས་པ་མཐོང་། ། | _則見十方佛。 |
| 210 | ཇི་ལྟར་སྒྱུ་མ་སྤྲུལ་པ་སྣ་ཚོགས་ལུས། ། | _如種種幻化， |
| 211 | རྟ་དང་གླང་པོ་བུད་མེད་སྐྱེས་པའི་གཟུགས། ། | _象馬狂夫等， |
| 212 | བྱིས་པ་སླུ་བ་བརྫུན་ཞིང་ཕྱིན་ཅི་ལོག ། | _誑惑愚倒者， |
| 213 | དེ་བཞིན་སྟོབས་བཅུ་རྣམས་ལ་བལྟ་བར་ བྱོས། ། | _如是觀十方。 |
| 214 | གང་དག་འདས་པའི་བདེ་གཤེགས་དཔག་མེད་དང་། །མ་བྱོན་རྒྱལ་བ་དེ་བཞིན་གང་སྣང་དག ། | _三世無量佛， |
| 215 | ཆོས་ཉིད་གཅིག་གྱུར་མཉམ་པ་མེད་པའི་སྐུ། ། | _同處法性身， |
| 216 | ཆོས་ཀྱི་དབྱིངས་ཀྱི་ཀླས་ཤིང་ནམ་མཁའ་འདྲ། ། | _無等等虛空，_極清淨法界。 |
| 217 | དེ་ལྟར་བྱང་ཆུབ་སེམས་དཔའ་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱི་དེ་བཞིན་གཤེགས་པའི་སྐུ་བསམ་གྱིས་ མི་ཁྱབ་པ་ལ་མངོན་པར་དད།  ཡིད་ཆེས། རབ་ཏུ་རྟོག ། ཐེ་ཚོམ་མི་ཟ། རྒྱ་ཆེར་དགའ་མགུ་སྟེ། རངས་པ་རྙེད་ནས། | _「如是，舍利子！是名如來不可思議身。 菩薩摩訶薩信受諦奉，清淨無疑，倍復踊躍，深生歡喜， |
| 218 | ངོ་མཚར་དང་། རྨད་དུ་འདུ་ཤེས་སྐྱེད་དོ། ། | 發希奇想。 |
| 219 | ཤཱ་རིའི་བུ་ཇི་ལྟར་ན། | 」_爾時佛告舍利子： |
| 220 | བྱང་ཆུབ་སེམས་དཔའ་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱི་དེ་བཞིན་གཤེགས་པའི་ དབྱངས་བསམ་གྱིས་མི་ཁྱབ་པ་ལ་མངོན་པར་དད།  ཡིད་ཆེས། རབ་ཏུ་རྟོག་པ་ནས་ངོ་མཚར་དང་རྨད་དུ་འདུ་ཤེས་ཀྱི་བར་དུ་འདུ་ཤེས་སྐྱེད་ཅེ་ན། | 「云何菩薩摩訶薩於如來不思議音聲，信受諦奉，清淨無疑，乃至發希奇想？ |
| 221 | འདི་ལྟར་ཤཱ་རིའི་བུ་དེ་བཞིན་གཤེགས་པ་ནི་འདུལ་བའི་དབང་གི་ཕྱིར་འཁོར་ཇི་ལྟ་བ་དེ་བཞིན་དུ་སྒྲ་འབྱུང་སྟེ།  སེམས་ཅན་ ཐམས་ཅད་རབ་ཏུ་དགའ་བར་བྱ་བའི་ཕྱིར་ཕྱོགས་བཅུའི་འཇིག་རྟེན་གྱི་ཁམས་ཐམས་ཅད་དུ་ཁྱབ་པར་བྱེད་མོད་ཀྱི། | 舍利子！如來出世，愍諸含識，敷演法化，所發音聲齊於眾會。 由所調伏眾生力故，如來音聲普遍十方無量世界，令諸眾生心歡喜故。 |
| 222 | ཤཱ་རིའི་བུ་དེ་བཞིན་གཤེགས་པ་འདི་སྙམ་དུ་ངས་དགེ་སློང་གི་འཁོར་ལོ་ནི་འདི་བཤད། དགེ་སློང་མའི་འཁོར་ལོ་ནི་འདི། དགེ་བསྙེན་གྱི་འཁོར་ལོ་ནི་འདི། དགེ་བསྙེན་མའི་ འཁོར་ལོ་ནི་འདི། བྲམ་ཟེའི་འཁོར་ལོ་ནི་འདི། རྒྱལ་རིགས་ཀྱི་འཁོར་ལོ་ནི་འདི། ཁྱིམ་བདག་གི་འཁོར་ལོ་ནི་འདི། ལྷའི་འཁོར་ལོ་ནི་འདི། ཚངས་པའི་འཁོར་ལོ་ནི་འདི་སྟེ། | 舍利子！然諸如來所出音聲，雖遍世界不作是念：『我為苾芻眾說法，我為苾芻尼眾說法，我為鄔波索迦眾、鄔波斯迦眾、婆羅門眾、剎帝利眾、長者眾、天眾、梵眾，如是等眾而為說法。 |
| 223 | འདི་ལྟ་སྟེ། མདོའི་སྡེ་དང་། དབྱངས་ཀྱིས་བསྙད་པའི་སྡེ་དང་། ལུང་དུ་བསྟན་པའི་སྡེ་དང་། ཚིགས་སུ་བཅད་པའི་སྡེ་དང་། ཆེད་དུ་བརྗོད་པའི་སྡེ་དང་། གླེང་གཞིའི་སྡེ་དང་། རྟོགས་པ་བརྗོད་པའི་སྡེ་དང་། དེ་ལྟ་བུ་བྱུང་བའི་སྡེ་དང་། སྐྱེས་པའི་རབས་ཀྱི་སྡེ་དང་། ཤིན་ཏུ་རྒྱས་པའི་སྡེ་དང་། རྨད་དུ་བྱུང་བའི་ཆོས་ཀྱི་སྡེ་དང་། གཏན་ལ་དབབ་པར་བསྟན་པའི་སྡེ་རྣམས་བཤད་པར་བྱའོ་སྙམ་དུ་མི་དགོངས་མོད་ཀྱི། | 』亦不作是念：『我今演說契經、應頌、記莂、伽他、自說、緣起、本事、本生、方廣、希法、譬喻、解釋，如是等趣十二分教。 』初未生念為之敷演。 |
| 224 | འོན་ཀྱང་ཤཱ་ རིའི་བུ་འཁོར་ཇི་ལྟ་བུ་འདུས་པར་གྱུར་པ། ཚངས་པའི་འཁོར་གྱི་བར་དུ་འདུས་པར་གྱུར་པ། དེ་དག་གི་དབང་པོའི་རིམ་པ་ཅི་འདྲ་བ་དང་། | 舍利子！如來隨諸眾集，所謂苾芻乃至梵眾，如其所聞種種正勤而為說法。 |

| 364 | རྣམ་པར་ཤེས་པ་ནི་ཡིད་ལ་བྱེད་པ་ལས་སྐྱེའོ། ། | 從作意生是名為識， |
| 365 | རྣམ་པར་ཤེས་པ་ནི་ཡོངས་སུ་རྟོག་པ་ལས་སྐྱེ་སྟེ་དེ་ནི་རྣམ་པར་ཤེས་པ་ཞེས་བྱའོ། ། | 從分別生是名為識。 |
| 366 | གང་འཛིན་པ་མེད་པས་སྙེམས་པ་དང་དམིགས་པ་མེད་རྣམ་པར་རིག་པ་མེད་ཅིང་མི་རྟོག་པ་དེ་ནི་ཡེ་ཤེས་ཞེས་བྱའོ། ། | 無取無執、無有所緣、無所了別、無有分別，是名為智。 |

| 368 | གཞན་ཡང་འདུས་ བྱས་ལ་སྤྱོད་པའི་ཆོས་ལ་རྣམ་པར་ཤེས་པ་ལ་གནས་ཤིང་གང་འདུས་བྱས་ལ་སྤྱོད་པའི་ཆོས་རྣམ་པར་ཤེས་པ་དེ་ནི་རྣམ་པར་ཤེས་པ་ཞེས་བྱའོ། ། | 所言識者，住有為法。 |
| 369 |  | 何以故？ |
| 370 | འདུས་མ་བྱས་ལ་ནི་རྣམ་པར་ཤེས་པ་རྒྱུ་བ་མེད་དེ། | 無為法中，識不能行。 |
| 371 | གང་འདུས་མ་བྱས་ཤེས་པ་དེ་ནི་ཡེ་ཤེས་ཞེས་བྱའོ། ། | 若能了達無為之法，是名為智。 |
| 372 |  | 又舍利子！ |
| 373 | གཞན་ཡང་གང་སྐྱེ་བ་དང་། འཇིག་པ་ལ་རབ་ཏུ་གནས་པ་དེ་ནི་རྣམ་པར་ཤེས་པའོ། ། | 住生滅者名之為識， |
| 374 | གང་སྐྱེ་བ་མེད་པ་དང་། འགག་པ་མེད་པ་ལ་གནས་པ་དེ་ནི་ཡེ་ཤེས་ཞེས་བྱའོ། ། | 不生不滅無有所住是名為智。 |
| 375 | དེ་ལྟར་ཤཱ་རིའི་བུ་འདི་ནི་རྣམ་པར་ཤེས་པ། འདི་ནི་ཡེ་ཤེས་ཏེ། | 舍利子！如是諸相若識若智，是名如來第三不思議大智。 |
| 376 | བྱང་ཆུབ་སེམས་དཔའ་དེ་བཞིན་གཤེགས་པ་རྣམས་ཀྱི་དེ་བཞིན་གཤེགས་པའི་ཡེ་ ཤེས་བསམ་གྱིས་མི་ཁྱབ་པ་དེ་ལ་མངོན་པར་དད།  ཡིད་ཆེས། རབ་ཏུ་རྟོག ། ཐེ་ཚོམ་མི་ཟ། | 若諸菩薩摩訶薩聞如是不思議大智無障無礙，一切法中依之而起，信受諦奉，清淨無疑， |
| 377 | རྒྱ་ཆེར་དགའ་མགུ་སྟེ།  རངས་པ་རྙེད་ནས་ | 倍復踊躍，深生歡喜， |
| 378 | ངོ་མཚར་དང་། རྨད་དུ་འདུ་ཤེས་སྐྱེད་དོ། ། | 發希奇想。 |

| 381 | དེ་བཞིན་ཕྱོགས་བཅུའི་འཇིག་རྟེན་ཁམས་ཀྱི་རྩྭ་རྣམས་ནི། ། | _十方界草木， |

| 383 | ལོ་ནི་བརྒྱ་སྟོང་དག་ཏུ་རྒྱ་མཚོར་དཀྲུགས་པ་རྣམས། ། | _億載磨于海。 |
| 384 | དེ་འདྲ་བ་ཡི་སྟོབས་བཅུ་ཡེ་ཤེས་ཕྲ་མངའ་བས། ། | _十力智深妙， |
