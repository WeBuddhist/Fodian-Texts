# Sutra of the Virtuous Woman of Magadha — aligned

| # | toh0346-bo | toh0346-zh |
|---|---|---|
| 1 | སངས་རྒྱས་དང་བྱང་ཆུབ་སེམས་དཔའ་ཐམས་ཅད་ལ་ཕྱག་འཚལ་ལོ། ། | 頂禮一切佛菩薩。 |
| 2 | སངས་རྒྱས་བཅོམ་ལྡན་འདས་མཉན་ཡོད་ན། རྒྱལ་བུ་རྒྱལ་བྱེད་ཀྱི་ཚལ་མགོན་མེད་ཟས་སྦྱིན་གྱི་ཀུན་དགའ་ར་བ་ན་བཞུགས་ཏེ། | 佛世尊在舍衛城祇樹給孤獨園。 |
| 3 | དེ་ནས་དེའི་ཚེ་མཉན་ཡོད་ན་མགོན་མེད་ཟས་སྦྱིན་གྱི་བུ་མོ་མ་ག་དྷ་བཟང་མོ་ཞེས་བྱ་བ་དད་པ་དང་ལྡན་པ། རང་བཞིན་བཟང་བ། བསམ་པ་དགེ་བ། བདག་དང་གཞན་ལ་ཕན་པའི་ཕྱིར་ཞུགས་པ་ཞིག་གནས་སོ། ། | 彼時，有給孤獨長者女，名摩竭陀賢，具足信心，稟性佳妙，意樂良善，兼利自他，住於舍衛城。 |
| 4 | ཇི་ཙམ་ན་བུ་རམ་ཤིང་འཕེལ་ཞེས་བྱ་བའི་གྲོང་ཁྱེར་ན་ | 於時福增城中， |
| 5 | ཚོང་དཔོན་གཞན་ཞིག་གནས་པ་ལ། | 別有商主， |
| 6 | དེའི་བུ་ཁྱུ་མཆོག་བྱིན་ཞེས་བྱའོ། ། | 其子名為牛授， |
| 7 | དེ་ཡང་གཞན་མུ་སྟེགས་པ་སྟེན་པས། | 親近外道， |
| 8 | གཅེར་བུ་པ་རྣམས་ལ་མངོན་པར་དད་པ་ཞིག་གནས་པ་དང་། | 深信諸尼犍子。 |
| 9 | གང་གི་ཚེ་བཅོམ་ལྡན་འདས་ཀྱིས་ཆོ་འཕྲུལ་ཆེན་པོ་རྣམ་པར་བསྟན་པ་དེའི་ཚེ། | 於時世尊現大神變， |
| 10 | མུ་སྟེགས་པ་རྣམས་མཐའ་འཁོར་ཏུ་ཀུན་ཏུ་གནས་ཏེ། | 諸外道皆住於邊城， |
| 11 | ལ་ལ་ནི་གྲོང་ཁྱེར་བཟང་བྱེད་ཅེས་བྱ་བ་ནའོ། ། | 或於作賢城， |
| 12 | ལ་ལ་ནི་མུད་གི་རི་ཀ་ཞེས་བྱ་བའི་ཡུལ་ནའོ། ། | 或於遨哩迦境內， |
| 13 | ལ་ལ་ནི་བུ་རམ་ཤིང་འཕེལ་ཞེས་བྱ་བའི་གྲོང་ཁྱེར་ན་གནས་སོ། ། | 或住福增城。 |
| 14 | དེའི་ཚེ་དེའི་དུས་ན། | 彼時 |
| 15 | ཁྱུ་མཆོག་བྱིན་དེའི་བར་དུ་ཁྱིམ་མ་བྱས་པ་དང་། | 牛授猶未成家， |
| 16 | དེ་ལ་གཅེར་བུ་པ་རྣམས་ཀྱིས་སྨྲས་པ། | 尼犍子告彼言： |
| 17 | མགོན་མེད་ཟས་སྦྱིན་གྱི་བུ་མོ་ | 「給孤獨長者有女， |
| 18 | མ་ག་དྷ་བཟང་མོ་ཞེས་བྱ་བ། | 名摩竭陀賢， |
| 19 | གཟུགས་བཟང་བ། | 形色妙好， |
| 20 | བལྟ་ན་སྡུག་པ། མཛེས་པ། | 觀之韶麗端嚴， |
| 21 | སྐྱེ་བོ་དམ་པ་རྣམས་དང་འདྲ་བ་ཞིག་ཡོད་དོ། ། | 如諸賢士。」 |
| 22 | ཇི་སྲིད་དེས་ཐོས་པ་དང་། | 牛授聞已， |
| 23 | བདག་ཉིད་གཅེར་བུ་པའི་ཆ་བྱད་དུ་བྱས་ཏེ། | 即作尼犍子裸形， |
| 24 | མཉན་ཡོད་དུ་སོང་ངོ་། ། | 往趣舍衛城。 |
| 25 | ཇི་ཙམ་ན་ | 未久， |
| 26 | ཁྱིམ་བདག་མགོན་མེད་ཟས་སྦྱིན་གྱི་ཁྱིམ་དུ་སློང་བའི་ཕྱིར་ཞུགས་པ་དང་། | 至已，往詣給孤獨長者家乞食， |
| 27 | དེས་བུ་མོ་དེ་མཐོང་ངོ་། ། | 即睹彼女， |
| 28 | མཐོང་བའི་མོད་ཁོ་ན་ལ་བུ་མོ་དེ་ལ་ཀུན་ཏུ་ཆགས་པར་གྱུར་ལ། | 便起愛著， |
| 29 | དེ་དེར་བསླངས་པའི་ཚེ་ཞྭའི་ནང་དུ་བླངས་སོ། ། | 乃以帽承接其所施物。 |
| 30 | དེ་ནས་བུ་མོ་དེས་ལོག་པར་སྤྱོད་པ་དེ་མཐོང་བ་དང་། | 彼女見其行止倒錯， |
| 31 | འདི་ནི་ཤེས་བཞིན་མེད་པར་སློངས་མོ་ལེན་ཏོ་ཞེས་བགད་དོ། ། | 不覺哂之，曰：「此人不具正知而來化緣。」 |
| 32 | དེ་ནས་ཁྱུ་མཆོག་བྱིན་དེ་ངོ་ཚ་བར་གྱུར་པ་དང་། | 牛授愧甚， |
| 33 | བུ་རམ་ཤིང་འཕེལ་གྱི་གྲོང་ཁྱེར་དུ་སོང་སྟེ་ | 返於福增城， |
| 34 | ཕ་ལ་སྨྲས་ནས་ | 稟報其父， |
| 35 | དེས་བུ་མོ་དེ་བསླངས་སོ། ། | 旋往提親。 |
| 36 | མགོན་མེད་ཟས་སྦྱིན་གྱིས་བཅོམ་ལྡན་འདས་ལ་ཞུས་པ་དང་། | 給孤獨長者遂來諮稟於佛， |
| 37 | བཅོམ་ལྡན་འདས་ཀྱིས་བཀའ་སྩལ་པ། | 世尊告曰： |
| 38 | གཞན་དུ་ན་གང་གི་ཚེ་མ་ག་དྷ་བཟང་མོ་འདི་བུ་རམ་ཤིང་འཕེལ་དུ་སོང་ན་ | 「摩竭陀賢若往福增城，未來某時， |
| 39 | རབ་ཏུ་བྱུང་བ་རྣམས་ཀྱི་བྱ་བ་དང་། སངས་རྒྱས་ཀྱི་བྱ་བ་བྱེད་པར་འགྱུར་རོ། ། | 將行出家事，行佛所作。 |
| 40 | ཡང་ཇི་སྲིད་ཅིག་ན་ཁྱིམ་བདག་མགོན་མེད་ཟས་སྦྱིན་གྱིས་ཉེ་དུ་རྣམས་ལ་ཡང་གོ་བར་བྱས་ནས་བྱིན་པ་དང་ | 於是給孤獨長者告諸親族已施其女，遂 |
| 41 | བུ་རམ་ཤིང་འཕེལ་དུ་ཁྱེར་རོ། ། | 攜其女往福增城。 |
| 42 | ཇི་ཙམ་ན་ | 未久， |
| 43 | དུས་གཞན་ཞིག་གི་ཚེ་ཁྱིམ་དེ་ན་གཅེར་པུ་པ་རྣམས་ཟན་ཟ་བ་དང་། | 諸尼犍子群至該家受食， |
| 44 | དེ་ལ་སྒྱུག་མོས་སྨྲས་པ། | 其姥語摩竭陀賢曰： |
| 45 | དེ་རིང་བདག་ཅག་གི་ཁྱིམ་ན་མཆོད་གནས་རྣམས་བཤོས་གསོལ་གྱིས་ | 「今日於家設供以款諸應供者， |
| 46 | ཚུར་ཤོག་མཆོད་གནས་རྣམས་ལ་ལྟོས་ཤིག། | 汝可出而觀之。」 |
| 47 | མ་ག་དྷ་བཟང་མོས་དེ་ཐོས་པ་དང་། | 摩竭陀賢聞言， |
| 48 | དགའ་བ་དང་། མགུ་བ་དང་། རངས་པ་དང་། ཡིད་བདེ་བ་སྐྱེས་ཏེ་བསམས་པ། | 歡欣喜悅，心念： |
| 49 | ངེས་པར་བཙུན་པ་ཤཱ་རིའི་བུའམ། མཽད་གལ་གྱི་བུ་ཆེན་པོ་ལ་སོགས་པ་ཉན་ཐོས་ཆེན་པོ་རྣམས་བྱོན་པར་གྱུར་ཏོ་སྙམ་ནས་ | 「此定為尊者舍利子、大目犍連等諸大聲聞至焉。」 |
| 50 | དེ་ཡིད་རབ་ཏུ་དགའ་བ་དང་། | 心極歡喜， |
| 51 | འཇིགས་པ་མེད་པར་སོང་བ་དང་། | 無畏而往， |
| 52 | "གཅེར་བུ་ནགས་ཀྱི་མ་ཧེ་འདྲ་བ། སྐྲ་རྣམས་བཏོགས་པ། ཕུག་རོན་གྱི་ཕྲུ་གུ་འདྲ་བའི་གཅེར་བུ་པ་རྣམས་མཐོང་ངོ་། །" | 乃見諸尼犍子周身赤裸，猶如林中水牛，髦髮盡除，宛若雛鴿。 |
| 53 | མཐོང་བ་དང་དེའི་མོད་ལ་མ་ག་དྷ་བཟང་མོ་ངོ་ཚ་སྟེ། | 摩竭陀賢見已，即生羞惡， |
| 54 | དེ་གདོང་གཞན་དུ་བལྟས་པ་དང་། | 轉視他方。 |
| 55 | དེ་ལ་སྒྱུག་མོ་དེས་སྨྲས་པ། | 其姥問曰： |
| 56 | བུ་མོ། ཁྱོད་ཅིའི་ཕྱིར་ཡི་མུག་པར་གྱུར། | 「新婦何故失望若此？」 |
| 57 | དེས་སྨྲས་པ། | 彼女答曰： |
| 58 | གང་འདི་ལྟ་བུ་མཆོད་གནས་ཡིན་ན་ | 「如若此輩得為應供者， |
| 59 | "མཆོད་གནས་མ་ཡིན་པ་གོ་ཇི་ལྟ་བུ་ཞིག་ཡོད་པར་འགྱུར།" | 則有何人不為應供者？ |
| 60 | དེ་ལ་དེས་སྨྲས་པ། | 其姥問曰： |
| 61 | བུ་མོ་ཁྱོད་ལ་འདི་བས་ཆེས་ཁྱད་པར་དུ་འཕགས་པའི་སྟོན་པ་འགའ་ཞིག་ཡོད་དམ། | 婦有聖師，更愈此乎？ |
| 62 | བུ་མོས་སྨྲས་པ། | 彼女答曰： |
| 63 | "བདག་གི་ཕའི་གཙུག་ལག་ཁང་རྒྱལ་བྱེད་ཀྱི་ཚལ་ན་" | 「吾父祇園精舍中， |
| 64 | སངས་རྒྱས་ཞེས་བྱ་བའི་སྟོན་པ་བཞུགས་ཏེ། | 住有稱名佛陀之導師， |
| 65 | "དེ་ནི་རྒྱུ་བ་དང་། མི་རྒྱུ་བའི་འཇིག་རྟེན་གྱི་མཆོད་གནས་ཡིན་ནོ། །" | 彼堪為一切動靜世間所應供者。 |
