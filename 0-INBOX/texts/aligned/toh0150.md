# The Noble Mahayana Sutra of the Seven Dharmas Requested by the Holy Avalokiteshvara — aligned

| # | toh0150-bo | toh0150-zh |
|---|---|---|
| 1 | བཅོམ་ལྡན་འདས་འཇམ་དཔལ་གཞོན་ནུར་གྱུར་པ་ལ་ཕྱག་འཚལ་ལོ། ། | 頂禮世尊妙吉祥童子。 |
| 2 | འདི་སྐད་བདག་གིས་ཐོས་པ་། | 如是我聞： |
| 3 | དུས་གཅིག་ན། | 一時， |
| 4 | བཅོམ་ལྡན་འདས་རྒྱལ་པོའི་ཁབ་བྱ་རྒོད་ཕུང་པོའི་རི་ལ་ | 世尊在王舍城靈鷲山中， |
| 5 | དགེ་སློང་སྟོང་ཉིས་བརྒྱ་ལྔ་བཅུའི་དགེ་སློང་གི་དགེ་འདུན་ཆེན་པོ་དང་། | 與大比丘僧千二百五十人俱， |
| 6 | བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་རབ་ཏུ་མང་པོ་དང་ཐབས་ཅིག་ཏུ་ཞུགས་ཏེ། | 并與眾多菩薩摩訶薩大眾俱。 |
| 7 | དེ་ནས་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་འཕགས་པ་སྤྱན་རས་གཟིགས་དབང་ཕྱུག་སྟན་ལས་ལངས་ཏེ། | 爾時，聖觀自在菩薩摩訶薩從座而起， |
| 8 | བླ་གོས་ཕྲག་པ་གཅིག་ཏུ་གཟར་ནས་ | 偏袒右肩， |
| 9 | པུས་མོ་གཡས་པའི་ལྷ་ང་པད་མའི་ལྟེ་བ་ལ་བཙུགས་ཏེ། | 以右膝著蓮花臺上， |
| 10 | བཅོམ་ལྡན་འདས་ག་ལ་བ་དེར་ | 向於佛所， |
| 11 | ཐལ་མོ་སྦྱར་བ་བཏུད་དེ། | 合掌禮敬， |
| 12 | བཅོམ་ལྡན་འདས་ལ་འདི་སྐད་ཅེས་གསོལ་ཏོ། ། | 白世尊言： |
| 13 | བཅོམ་ལྡན་འདས་ | 「世尊！ |
| 14 | བྱང་ཆུབ་ཀྱི་སེམས་བསྐྱེད་མ་ཐག་པའི་བྱང་ཆུབ་སེམས་དཔས་ | 菩薩初發菩提心已， |
| 15 | ཆོས་དུ་ཞིག་ལ་བསླབ་པར་བགྱི། | 當學幾法？。」 |
| 16 | དེ་སྐད་ཅེས་གསོལ་པ་དང་། བཅོམ་ལྡན་འདས་ཀྱིས་བྱང་ཆུབ་སེམས་དཔའ་སེམས་དཔའ་ཆེན་པོ་འཕགས་པ་སྤྱན་རས་གཟིགས་དབང་ཕྱུག་ལ་འདི་སྐད་ཅེས་བཀའ་སྩལ་ཏོ། ། | 如是問已，世尊告聖觀自在菩薩摩訶薩云： |
| 17 | རིགས་ཀྱི་བུ་བྱང་ཆུབ་ཏུ་སེམས་བསྐྱེད་མ་ཐག་པའི་བྱང་ཆུབ་སེམས་དཔས་ | 「善男子！菩薩初發菩提心已， |
| 18 | ཆོས་བདུན་ལ་བསླབ་པར་བྱ་སྟེ། | 應學七法。 |
| 19 | བདུན་གང་ཞེ་ན། | 云何為七？ |
| 20 | འདི་ལྟ་སྟེ། | 謂： |
| 21 | རྣམ་པར་རྟོག་པས་ | 雖起分別， |
| 22 | ཀྱང་འདོད་པ་ལ་སྟེན་པར་མི་བྱེད་ན་ | 亦不應依止貪欲， |
| 23 | དབང་པོ་གཉིས་ཀྱིས་སྦྱོར་བ་ལྟ་སྨོས་ཀྱང་ཅི་དགོས། | 何況二根交合； |
| 24 | ཐ་ན་རྨི་ལམ་གྱི་ནང་དུ་ཡང་ | 乃至夢中， |
| 25 | མི་དགེ་བའི་བཤེས་གཉེན་སྟེན་པར་མི་བྱེད་པ་དང་། | 亦不應依不善知識； |
| 26 | བྱ་དང་འདྲ་བའི་སེམས་ཀྱིས་ | 應如禽鳥， |
| 27 | ཡོངས་སུ་འཛིན་པ་མེད་པར་བྱ་བ་དང་། | 心無攝取； |
| 28 | ཐབས་དང་ཤེས་རབ་ལ་མཁས་པས་ | 應以善巧方便慧故， |
| 29 | ང་རྒྱལ་དང་། ང་ར་འཛིན་པ་མེད་པར་བྱ་བ་དང་། | 無有我慢，亦無我執； |
| 30 | དངོས་པོ་དང་དངོས་པོ་མེད་པ་སྤང་ས་ནས་ | 有實無實，皆悉應斷， |
| 31 | སྟོང་པ་ཉིད་ཀྱི་རྣམ་པར་ཐར་པ་བརྟན་པོ་དང་ལྡན་པར་བྱ་བ་དང་། | 於空解脫，堅固具足； |
| 32 | ཡང་དག་པར་བདེན་པ་མ་ཡིན་པའི་ཀུན་དུ་རྟོག་པའི་ཤེས་པས་ | 應以［了悟諸法］非諦實之分別智， |
| 33 | སྒྱུ་མ་དང་། རྨི་ལམ་དང་འདྲ་བར་འཁོར་བ་ལས་ | 於輪迴幻夢， |
| 34 | མངོན་པར་དགའ་བར་བྱ་བ་མ་ཡིན་པ་དང་། | 無所好樂； |
| 35 | རྒྱུ་དང་འབྲས་བུ་ལ་སྐུར་པ་གདབ་པར་མི་བྱ་བ་སྟེ། | 不謗因果。 |
| 36 | རིགས་ཀྱི་བུ་བྱང་ཆུབ་ཏུ་སེམས་བསྐྱེད་མ་ཐག་པའི་བྱང་ཆུབ་སེམས་དཔས་ | 善男子！菩薩初發菩提心， |
| 37 | ཆོས་བདུན་པོ་དེ་དག་ལ་བསླབ་པར་བྱའོ། ། | 應學如是七法。」 |
| 38 | བཅོམ་ལྡན་འདས་ཀྱིས་དེ་སྐད་ཅེས་བཀའ་སྩལ་ནས། | 世尊說是語已， |
| 39 | བྱང་ཆུབ་སེམས་དཔའ་འཕགས་པ་སྤྱན་རས་གཟིགས་དབང་ཕྱུག་དང་། དགེ་སློང་དེ་དག་དང་བྱང་ཆུབ་སེམས་དཔའ་དེ་དག་ཡི་རང་ས་ཏེ་ | 聖觀自在菩薩及彼諸比丘、菩薩，皆大歡喜， |
| 40 | བཅོམ་ལྡན་འདས་ཀྱིས་གསུང་ས་པ་ལ་མངོན་པར་བསྟོད་དོ། ། | 於世尊所說，稱揚讚歎。 |
| 41 | འཕགས་པ་སྤྱན་རས་གཟིགས་དབང་ཕྱུག་གིས་ཞུས་པ་ཆོས་བདུན་པ་ཞེས་བྱ་བ་ཐེག་པ་ཆེན་པོའི་མདོ་རྫོགས་སོ།། །། | 聖觀自在菩薩所問七法大乘經 |
| 42 | རྒྱ་གར་གྱི་མཁན་པོ་དཱི་པཾ་ཀ་ར་ཤྲཱི་ཛྙཱ་ན་དང་། | 印度親教師地槃迦囉師利闍那（吉祥燃燈智，即阿底峽尊者） |
| 43 | ལོ་ཙྪ་བ་དགེ་སློང་དགེ་བའི་བློ་གྲོས་ཀྱིས་བསྒྱུར་བ།། | 及譯師比丘給威羅珠（善慧）翻譯。 |
